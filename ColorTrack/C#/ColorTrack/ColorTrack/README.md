# ColorTrack - VACS Analyzer

ColorTrack은 시야각에 따른 색상 변화 측정을 위한 색도 분석 도구입니다. Python 버전을 C#으로 완전히 재구현하여 Windows 환경에서 더 나은 성능과 사용성을 제공합니다.

## 주요 기능

### 🎯 핵심 분석 기능
- **CIE 1931 색도도 분석**: 표준 CIE 1931 xy 색공간에서의 색상 분포 시각화
- **CIE 1976 색도도 분석**: CIE 1976 u'v' 색공간에서의 더 균등한 색상 분포 분석
- **기하 중앙값 계산**: Weiszfeld 알고리즘을 사용한 정확한 색상 중심점 계산
- **CIEDE2000 색차 계산**: 최신 색차 공식을 사용한 정밀한 색상 차이 측정

### 📊 시각화 기능
- **실시간 플롯 업데이트**: 각도별 체크박스를 통한 즉석 데이터 필터링
- **Blackbody Locus 표시**: 다양한 간격(100K, 500K, 1000K, 1500K)의 흑체복사 곡선
- **등상관색온도선(DUV Lines)**: 색온도별 수직선 표시로 정확한 색온도 분석
- **색상 변화 화살표**: 시야각 변화에 따른 색상 이동 방향과 크기 시각화

### 🎨 배경 이미지 지원
- **좌표계색보기**: CIE 1931/1976 표준 색도도 배경 이미지 표시
- **투명도 조절**: 배경 투명도를 10-100% 범위에서 자유롭게 조절
- **색좌표경계**: 스펙트럼 궤적(spectral locus) 경계선 표시

## 파일 구조

```

│   ├── GeometricMedianEngine.cs   # 기하 중앙값 계산 엔진
│   ├── ColorConversionEngine.cs   # 색공간 변환 및 색차 계산
```

## 설치 및 실행

### 1. 개발 환경 설정
```bash
# Visual Studio 2022 또는 Visual Studio Code 설치

dotnet --version
```

## 사용법

### 📁 데이터 로드
1. **"📁 Load Data"** 버튼 클릭
2. CSV 파일 선택 (각도별 x, y 좌표가 포함된 형식)
3. 데이터 로드 완료 후 상태바에 파일명과 행 수 표시

### 📐 시야각 선택
- **0°, 15°, 30°, 45°, 60°** 체크박스에서 분석하고자 하는 각도 선택
- 선택된 각도의 데이터만 플롯에 표시
- 실시간으로 플롯이 업데이트됨

### 🌡️ Blackbody Locus 설정
- **100K, 500K, 1000K, 1500K** 간격별로 등상관색온도선 표시 선택
- 여러 간격을 동시에 선택 가능
- 색온도 레이블이 함께 표시됨

### ⚙️ 고급 설정
**설정 버튼(⚙)** 클릭으로 접근:
- **좌표계색보기**: 배경 이미지 표시/숨기기
- **색좌표경계**: 스펙트럼 궤적 경계선 표시/숨기기
- **좌표계색투명도**: 배경 이미지 투명도 조절 (10-100%)
- **Blackbody Locus Intervals**: 각 간격별 세부 설정

### 💾 결과 저장
- **"💾 Save Plot"** 버튼으로 현재 플롯을 PNG 형식으로 저장
- 고해상도(300 DPI) 이미지로 저장되어 보고서 작성에 적합

## 데이터 형식

CSV 파일은 다음과 같은 컬럼 구조를 가져야 합니다:

```csv
0_x,0_y,15_x,15_y,30_x,30_y,45_x,45_y,60_x,60_y
0.3127,0.3290,0.3130,0.3285,0.3135,0.3280,0.3140,0.3275,0.3145,0.3270
0.3125,0.3292,0.3128,0.3287,0.3133,0.3282,0.3138,0.3277,0.3143,0.3272
...
```

- `{각도}_x`: 해당 각도에서의 CIE x 좌표
- `{각도}_y`: 해당 각도에서의 CIE y 좌표

## 분석 결과 해석

### 색상 변화 화살표
- **화살표 방향**: 시야각 증가에 따른 색상 변화 방향
- **화살표 길이**: 색상 변화의 크기 (거리)
- **색상별 구분**: 각 전환 단계별로 다른 색상으로 표시

### 수치 정보
- **Δxy**: CIE 1931 좌표계에서의 유클리드 거리
- **Δuv**: CIE 1976 좌표계에서의 유클리드 거리
- **ΔE00**: CIEDE2000 색차 (인간 시각 인지 기반)
- **Total ΔE00**: 전체 시야각 범위에서의 총 색차

### 기하 중앙값 (Geometric Median)
- 각 각도별 측정 데이터의 중심점
- 외곽점의 영향을 최소화한 견고한 중심 추정
- 빈 원으로 표시되어 산점도와 구분

## 고급 기능

### 🔍 줌 및 팬 기능
- **마우스 휠**: 줌 인/아웃
- **클릭+드래그**: 팬 (이동)
- **네비게이션 버튼**: 각 플롯 우상단의 버튼 사용
  - **⌂**: 데이터에 맞춰 화면 맞춤
  - **⊕**: 확대
  - **⊖**: 축소

### 📏 실시간 좌표 표시
- 마우스 커서 위치의 정확한 색도 좌표 실시간 표시
- CIE 1931: x, y 좌표
- CIE 1976: u', v' 좌표

### 🎯 정밀한 색온도 분석
- Planck 흑체복사 법칙 기반 정확한 색온도 곡선
- 사용자 정의 온도 간격으로 세밀한 분석 가능
- 주요 색온도 지점 자동 라벨링

## 문제 해결

### 배경 이미지가 표시되지 않는 경우
1. `Images/` 폴더에 배경 이미지 파일 확인
2. 파일명: `cie1931_background_clean.png`, `cie1976_background_clean.png`
3. 설정에서 "좌표계색보기" 체크박스 확인

### CSV 로드 오류
1. 파일 인코딩 확인 (UTF-8 권장)
2. 컬럼 헤더 형식 확인: `{각도}_x`, `{각도}_y`
3. 데이터 형식 확인 (숫자 데이터, 쉼표 구분)

### 성능 최적화
1. 대용량 데이터의 경우 샘플링 고려
2. 불필요한 각도 체크박스 해제
3. 배경 이미지 투명도 조절로 렌더링 성능 향상
