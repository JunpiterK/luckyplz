🎯 비전문가를 위한 가이드 — 양산 운영의 4가지 어려운 질문

"양산 운영자가 매일 부딪히는 4가지 진짜 어려운 질문"

1·2차가 "예측"과 "제어"였다면, 3차는 "왜?", "관계가 뭔가?", "본 적 없는 것을 어떻게 잡나?", "사내 자료로 어떻게 답하나?"를 푸는 도구입니다. 이 4가지는 모두 인간 엔지니어가 매일 풀려고 애쓰는 질문이고, AI가 이걸 도와주는 모습을 보면 가치가 즉시 보입니다.

⑨
GBT + SHAP
"왜 수율이 떨어졌나"
💡 일상 비유
학생 시험 점수 분석: 5과목 점수 합계가 평균보다 낮았다 → "어느 과목이 평균을 끌어내렸는지" 과목별 기여도 분석. 영어 −15점, 수학 +5점, 과학 −8점 ... 식으로 +/−를 모두 보여줌.
🏭 fab 매핑
한 lot의 yield가 평균보다 −2%p 떨어졌을 때: chamber A의 RF 변동 −0.8%p, chamber B의 압력 +0.1%p, recipe step 3 시간 −0.5%p... 어느 변수가 주범인지 즉시 추적. 엔지니어 RCA 시간 1일 → 5분.
🎯 시뮬레이션에서 볼 것
SHAP 막대그래프에서 "빨간 막대(+) = 결과를 끌어올린 변수, 파란 막대(−) = 끌어내린 변수". 막대 길이가 영향력 크기. 한눈에 RCA 결과를 볼 수 있는 게 이 도구의 가치.
⑩
GNN (그래프 신경망)
"관계가 뭔가"
💡 일상 비유
회사 조직도에서 영향 추적: 한 부서가 늦어지면 어느 부서까지 영향을 주나? 직접 연결된 부서뿐 아니라 2단계 · 3단계 떨어진 부서까지 메시지를 전달해 영향도 계산. SNS의 친구 추천도 같은 원리.
🏭 fab 매핑
chamber → tool → lot 그래프: 한 lot이 통과한 chamber 12대 + tool 5대 + recipe 3개의 관계망. 한 lot의 yield 저하 원인이 어느 chamber에 있는지를 그래프 전체 패턴에서 추론. TSMC HGT가 대표 사례.
🎯 시뮬레이션에서 볼 것
메시지 패싱 라운드가 진행되며 "색깔이 비슷한 노드는 비슷한 영향을 받는다"는 그룹화가 자동으로 나타남. 학습 없이 그래프 구조만으로 그룹이 보이는 게 GNN의 가치.
⑪
PatchCore (anomaly)
"본 적 없는 결함도 잡기"
💡 일상 비유
옷 가게 점원이 정상 옷 패턴을 외움: 결함 옷은 본 적 없어도, 정상 옷의 박음질·패턴을 충분히 외워두면 이상한 옷이 들어왔을 때 즉시 알아챔. "이건 우리 매장 옷이 아닌 것 같다"는 직감.
🏭 fab 매핑
OLED Mura 검출: Mura 종류는 수십 가지 + 새 종류가 계속 나타남 → 결함 라벨로 학습 불가능. 양품 panel 1만 장만 학습해 두고 "정상에서 떨어진 모든 것"을 anomaly로 잡음. 본 적 없는 새 결함도 즉시 검출.
🎯 시뮬레이션에서 볼 것
정상 영역에서 멀어질수록 "anomaly score" 빨간 점이 진해짐. 결함 클래스를 모르고도 "이상하다"를 정량화. 양산 라인의 surprise 결함 대응의 핵심.
⑫
LLM + RAG
"사내 자료로 답하기"
💡 일상 비유
도서관 사서: 손님 질문에 사서가 "잠시만요" → 관련 책 3권 가져와서 → 그 책들을 토대로 답변. 사서가 책을 다 외우는 게 아니라 그때그때 찾아서 답함. 거짓말(환각)이 줄고 출처가 명확.
🏭 fab 매핑
사내 EDM 코파일럿: 신입이 "ECN-1129 사유?" 물으면 → 사내 EDM에서 ECN 문서 + 8D + SOP 검색 → IBM Watson이 종합 답변 + 출처 표시. 10년차 엔지니어 한 명이 옆에 앉아 도와주는 효과.
🎯 시뮬레이션에서 볼 것
질문 → 검색(top-K chunk) → 증강(프롬프트 조립) → 생성(답변+출처) 3초 안에 일어나는 4단계. 출처 인용이 함께 나오는 게 핵심 — 답변을 검증할 수 있어야 신뢰가 생김.
🔗 이 4가지가 양산 운영에서 어떻게 함께 작동하나 — 한 lot 분석 시나리오
상황: 어제 lot #2024-1234의 yield가 평균보다 −2%p 떨어짐. 엔지니어가 답을 찾기 위해:

① GBT/SHAP(⑨)이 즉시 RCA — "chamber B의 RF 변동이 60% 기여, recipe step 3 시간이 25% 기여"
② GNN(⑩)이 chamber 그래프 분석 — "chamber B와 같은 tool 그룹의 다른 chamber 3대도 영향 받았을 가능성"
③ PatchCore(⑪)가 panel 검사 — "3대 chamber 출력에서 새로운 형태의 미세 mura 검출" (라벨 없이)
④ 엔지니어가 LLM+RAG(⑫)에 "이번 mura 종류 과거에 본 적 있나?" 질문 → "2023.07 ECN-0814가 유사 사례, 워밍업 시간 +6시간으로 해결됨" 답변 + 출처

→ 4가지가 1시간 안에 RCA → 진단 → 처방까지 완성. 인간 엔지니어 혼자 했다면 1~3일 걸렸을 작업.

FOUNDATIONAL · 2001 · Friedman (Gradient Boosting) / 2016 · Chen (XGBoost) / 2017 · Lundberg (SHAP)

GBT + SHAP — 표 데이터의 왕 + "왜 그렇게 예측했나" 설명

Tabular(표 형태) 데이터의 분류·회귀에서는 신경망보다 Gradient Boosted Trees가 여전히 강합니다. 수율 예측·RCA의 사실상 표준. SHAP은 "왜 이 예측이 나왔나"를 게임이론으로 분해.

WHY · 왜 만들어졌나

"이미지·텍스트가 아닌 표 데이터"에서는 신경망보다 트리가 강하다

딥러닝이 이미지·NLP를 평정한 후에도 표 형태(tabular) 데이터는 여전히 트리 기반 모델이 우세합니다. 이유는 — ① 표 데이터는 변수마다 의미·스케일이 달라 normalization 효과가 약하고, ② 변수 간 비선형 상호작용이 복잡하고, ③ 신경망은 이런 데이터에서 과적합하기 쉽습니다.

2001년 Friedman의 Gradient Boosting Machines가 핵심 아이디어를 제시했습니다 — "한 트리의 오차를 다음 트리가 예측하도록 학습". 이 잔차를 줄여가는 가산 모델이 점차 강력한 앙상블을 만듭니다. 2016년 Tianqi Chen의 XGBoost가 이를 산업 수준 성능으로 구현해 Kaggle 대회를 평정했고, 오늘날 fab의 수율 예측·RCA의 사실상 표준이 됐습니다.

하지만 트리 앙상블은 "예측은 잘 하지만 왜 그런지 설명이 어렵다"는 black-box 문제가 있었습니다. 2017년 Lundberg & Lee의 SHAP이 게임이론의 Shapley value를 ML 해석에 적용해 이 문제를 해결 — "각 feature가 이 예측에 얼마나 기여했는가를 수학적으로 정직하게 분해".

Friedman (2001). "Greedy Function Approximation", Annals of Statistics. / Chen & Guestrin (2016). "XGBoost", KDD 2016. / Lundberg & Lee (2017). "A Unified Approach to Interpreting Model Predictions", NeurIPS 2017.

핵심 용어 4개

decision tree결정 트리

"feature가 임계값을 넘는가?"의 yes/no 분기로 데이터를 분할. 한 트리는 약하지만 여러 개를 앙상블하면 강함.

gain (information gain)정보 이득

"이 분기가 얼마나 좋은가?"의 척도. 분기 전후의 불순도(Gini, entropy) 차이. 트리는 매번 gain 최대 분기 선택.

Shapley value (φ_i)샤플리 값

"feature i가 이 예측에 기여한 정도". 게임이론에서 협력 게임의 공정한 분배. 모든 feature 조합을 평균해 계산.

baseline기준값

"feature를 모를 때의 예측값" — 보통 학습 데이터의 평균. SHAP 분해는 baseline에서 시작해 feature 기여도를 더해 prediction에 도달.

Shapley value 한 줄 정의 φ_i = Σ_{S ⊆ N\{i}} [|S|! · (|N|−|S|−1)! / |N|!] · [v(S∪{i}) − v(S)] 직관: "feature i를 추가했을 때 예측값이 얼마나 변하나"를 모든 feature 부분집합 S에 대해 가중평균 → 만족 성질: φ_baseline + Σ φ_i = prediction (정직한 분해)
SIMULATION · 데모 사용법
  1. 2D 산점도 — RF Power(x축) × Gas Flow(y축)에 60개 lot이 있고, 색깔이 yield (초록=양품, 빨강=불량)입니다.
  2. + Split 추가를 누르면 트리가 가장 정보 이득(gain)이 큰 분기를 자동 선택해 축에 평행한 선으로 표시합니다.
  3. 오른쪽 위에 분기 순서가 누적됩니다 — gain 값과 함께. 6개까지 추가 가능.
  4. 분할이 늘어날수록 배경 색이 학습된 결정 영역을 보여줍니다 (분홍=불량 영역, 청록=양품 영역).

  6. SHAP 분해: baseline + φ_RF + φ_Gas = prediction의 막대 그래프. 각 feature가 양수 기여인지 음수 기여인지 색으로 표시.

10
FOUNDATIONAL · 2017 · Kipf & Welling (GCN) / 2020 · Hu (HGT)

GNN — 그래프 구조 자체에서 학습한다

fab은 본질적으로 그래프입니다 — chamber와 chamber가 lot 흐름으로 연결되고, recipe가 chamber를 잇고. 이런 관계 구조 자체를 모델에 직접 입력하는 알고리즘이 GNN. TSMC HGT 수율 RCA가 대표 사례.

WHY · 왜 만들어졌나

2017년 이전: 그래프 데이터를 신경망에 넣을 표준이 없었다

소셜 네트워크(친구 관계), 지식 그래프, 분자 구조, fab의 chamber-lot 연결 — 이런 데이터는 본질적으로 노드(node) + 엣지(edge)의 그래프 구조입니다. 기존 신경망(CNN, RNN)은 격자나 시퀀스를 가정하기 때문에 그래프에 직접 적용하기 어려웠습니다.

2017년 Kipf & Welling의 GCNGraph Convolutional Network 논문이 결정적 돌파구를 만들었습니다. 핵심 아이디어 — "각 노드는 이웃 노드들의 평균을 받아 자신을 갱신". 이 단순한 메시지 패싱(message passing)을 여러 layer 쌓으면 멀리 있는 노드 정보까지 통합 가능. 한 layer면 1-hop 이웃, L layer면 L-hop 이웃까지.

이후 GAT(2018, attention 기반), HGT(2020, 이질적 노드/엣지 타입 분리), GraphTransformer(2021) 등으로 발전. fab에서는 chamber/tool/recipe/lot이 모두 다른 종류 노드라서 이질 그래프(heterogeneous graph)가 자연스럽고, 그래서 HGT가 TSMC의 수율 RCA에 채택됐습니다.

Kipf & Welling (2017). "Semi-Supervised Classification with Graph Convolutional Networks", ICLR 2017. / Hu et al. (2020). "Heterogeneous Graph Transformer", WWW 2020.

핵심 용어 4개

node (vertex)노드

그래프의 기본 단위. fab에서는 chamber, tool, recipe, lot 등. 각 노드는 feature 벡터를 가짐.

edge엣지

두 노드의 연결. fab에서는 "lot이 chamber를 통과", "chamber가 같은 tool 그룹". 방향성/시간/타입이 있을 수 있음.

message passing메시지 패싱

"각 노드가 이웃 노드들의 정보를 모아 자신을 갱신"하는 한 step. 여러 layer 쌓으면 멀리 있는 노드 정보까지 통합.

heterogeneous graph이질 그래프

노드 타입이 여러 종류 (chamber/tool/recipe/lot). HGT는 타입별로 attention parameter를 분리해 학습.

GCN 한 layer의 메시지 패싱 h_v^{l+1} = σ( W · MEAN({h_u^l : u ∈ N(v)}) + b ) ↓ 풀이 1. 각 노드 v의 이웃 N(v)을 모음 2. 이웃들의 hidden state h_u의 평균(또는 가중합) 3. 학습 가능한 W, b로 변환 + 비선형 σ 4. = 다음 layer의 v의 hidden state h_v
SIMULATION · 데모 사용법
  1. 7개 chamber(A~G)와 11개 엣지로 이루어진 그래프입니다. 어느 한 chamber에 이상값(+1.0)이 주입된 상태로 시작.
  2. + 1 round 메시지 패싱을 누르면 모든 노드가 동시에 tanh(0.5·자신 + mean(이웃)) 으로 갱신됩니다.
  3. 노드 색이 변합니다 — 빨강(+값), 파랑(−값), 회색(0). 이상값이 그래프 따라 전파되는 모습이 시각화됩니다.
  4. 오른쪽 패널은 각 노드의 round별 추적표. 각 round에서 각 노드의 값이 색상 사각형 + 숫자로 표시됩니다.
  5. 3-4 round 후에는 정보가 충분히 퍼져서 최종 분류(이상 전파 / 주의 / 정상)가 나옵니다.
  6. 소스 노드를 변경하면 다른 위치에서 시작했을 때 전파 패턴이 어떻게 다른지 비교할 수 있습니다.
Chamber 그래프 메시지 패싱 — 이상값이 그래프를 따라 전파
소스 노드
"+ 1 round" 버튼으로 메시지 패싱을 시작하세요.
노드=chamber. 엣지=lot 흐름. 색=feature 값(빨강+/회색0/파랑−). 우측=round별 추적.
INDUSTRY · 산업 적용

TSMC HGT 수율 RCA — 양산 적용 대표 사례

  • TSMC HGT (IEDM 2022, 2023) — chamber/tool/recipe/lot 4가지 노드 타입을 별도 attention head로 학습. 3nm 양산 첫 분기 yield ramp 30%+ 가속.
  • Time-aware edge — lot이 통과한 시간 정보를 edge timestamp로 추가. "2024년 5월 chamber A를 거친 lot"과 "2024년 6월의 같은 chamber"가 다른 분포일 수 있음을 학습.
  • Samsung 메모리 시도 — chamber 그래프 RCA에 GNN 적용 검토 중 (구체 양산 발표는 미공개).

도구 — PyTorch Geometric · DGL(Deep Graph Library). 산업 적용 시 라벨이 적은 환경에서는 GraphSAGE의 sampling 방식이 효과적.

11
FOUNDATIONAL · 2022 · Roth, Pemula, Zepeda, Schölkopf, Brox, Gehler (Amazon & MPI)

PatchCore — "정상 이미지만으로" 결함을 검출한다

fab의 결함은 long-tail이라 라벨이 부족합니다. PatchCore는 "라벨 0장으로 시작 가능"한 anomaly detection의 SOTA. MVTec AD 벤치마크에서 99.6% AUROC 달성.

WHY · 왜 만들어졌나

2022년 이전: 이상감지 모델은 학습이 까다로웠다

fab의 결함 데이터는 long-tail 분포 — 정상 이미지는 무한대지만 결함은 1년에 수십 건만 발생하는 경우도 있습니다. 그래서 supervised learning은 작동하지 않습니다. "정상만으로 학습"하는 unsupervised anomaly detection이 필요한데, 기존 방법들(autoencoder reconstruction error, GAN-based 등)은 학습이 까다롭고 false alarm이 많았습니다.

2022년 Amazon과 Max Planck Institute의 Roth 등이 발표한 PatchCore는 충격적으로 단순한 접근으로 SOTA를 달성했습니다. 핵심 아이디어 — "학습 없이! 사전학습된 CNN(WideResNet 등)으로 정상 이미지 patch들의 임베딩을 메모리뱅크에 저장만 하고, 새 이미지는 가장 가까운 정상 patch와의 거리로 판정".

이 단순한 방법이 MVTec AD 벤치마크에서 99.6% AUROC로 당시 모든 복잡한 학습 기반 방법을 추월했습니다. 산업 검사 vision의 사실상 표준이 됐고, 후속 EfficientAD(2023)는 1ms 추론까지 줄여 인라인 검사 라인에 직접 투입 가능. Applied Materials ExtractAI의 백본이기도 합니다.

Roth et al. (2022). "Towards Total Recall in Industrial Anomaly Detection", CVPR 2022. arXiv:2106.08265.

핵심 용어 4개

memory bank메모리뱅크

"정상 이미지들의 임베딩을 모두 저장한 데이터베이스". 학습 X — 그냥 모은 것. 새 이미지는 이 안에서 nearest를 찾아 거리로 판정.

embedding임베딩

사전학습된 CNN(ResNet/DINOv2)으로 이미지를 고차원 벡터로 변환. "비슷한 이미지는 비슷한 벡터"의 성질이 핵심.

nearest neighbor최근접 이웃

새 이미지의 임베딩이 메모리뱅크 안에서 가장 가까운 정상의 임베딩과 얼마나 떨어져 있는가. 이 거리가 anomaly score.

threshold (τ)임계값

거리 > τ면 ANOMALY, 이하면 NORMAL. 양산 적용 시 false alarm rate와 detection rate를 trade-off해 결정.

PatchCore 추론 — 매우 단순 1. 학습 단계 (학습 없음): memory_bank = { embed(panel) : panel ∈ 정상 이미지 N장 } 2. 추론 단계: z_test = embed(test_image) d = min_{z ∈ memory_bank} ‖z_test − z‖ ← 최근접 거리 if d > τ: return "ANOMALY" else: return "NORMAL" 핵심: 학습 없이도 99% AUROC. 라벨 0장으로 시작 가능.
SIMULATION · 데모 사용법
  1. 왼쪽 위 큰 사각형은 테스트 입력 panel (그라디언트 + Mura 패턴). 왼쪽 아래 8개 작은 사각형은 정상 메모리뱅크.
  2. 중앙 위는 2D 임베딩 공간 — 정상 8장(파란 점)이 클러스터를 이루고, 테스트(빨간 점)가 가장 가까운 정상과 점선으로 연결.
  3. Mura 강도 슬라이더를 0 → 100으로 올려보세요. 임베딩 공간에서 빨간 점이 정상 클러스터에서 멀어지는 모습을 확인.
  4. 중앙 아래는 거리 막대 + 임계값 τ. 거리가 τ를 넘으면 막대가 빨강으로, 아래면 초록으로.
  5. 오른쪽은 anomaly heatmap — 각 픽셀에서 정상 평균과의 차이를 표시. Mura 영역이 빨갛게 강조.
  6. Mura 위치 변경으로 중앙/좌상/우하에 결함이 있을 때 검출 패턴 비교.
  7. 임계값 τ를 조절해 sensitivity 변화를 관찰. 너무 낮으면 false alarm, 너무 높으면 miss.

INDUSTRY · 산업 적용

  • EfficientAD (2023) — PatchCore 후속. Teacher-Student distillation으로 1ms 추론. 인라인 검사 라인에 직접 투입.

FOUNDATIONAL · 2020 · Lewis et al. (Facebook AI Research)

LLM + RAG — "사내 자료 검색 → 컨텍스트 주입 → 답변 생성"

LLM의 환각(hallucination) 문제를 푸는 표준 패턴. 답변하기 전에 사내 SOP·ECN·8D를 벡터 DB에서 검색해 컨텍스트로 주입. Samsung Display Watson + EDM, Micron Co-pilot, BOE Blue Whale, CSOT X-Intelligence 모두 이 골격.

WHY · 왜 만들어졌나

2020년 이전: LLM은 "그럴듯한 거짓"을 만들어내는 문제가 있었다

GPT-3 같은 대규모 언어 모델은 인터넷 수조 token으로 사전학습되지만, 두 가지 한계가 있었습니다 — ① 최신 정보 부재: 학습 시점 이후 정보를 모름. ② 환각(hallucination): 모르는 것을 그럴듯하게 지어냄. 사내 SOP를 묻는다고 학습 시 본 적 없는 회사 자료를 정확히 답할 수 없습니다.

2020년 Facebook AI Research의 Lewis 등이 발표한 RAGRetrieval-Augmented Generation가 표준 해법을 제시했습니다. 핵심 아이디어 — "답변하기 전에 외부 지식 베이스(벡터 DB)에서 관련 문서를 검색해서 LLM의 입력에 포함시킨다".

결과: ① 사내 자료를 정확히 인용 가능, ② 자료가 업데이트되면 즉시 반영, ③ 답변에 출처(citation)을 함께 표시 가능. 오늘날 산업 LLM 코파일럿의 사실상 표준. Samsung Display의 Watson + EDM 통합 LLM도 이 패턴이며, 차별점은 EDM의 PPT/Excel을 자동 변환·벡터화 + 프로젝트별 인덱스입니다.

Lewis et al. (2020). "Retrieval-Augmented Generation for Knowledge-Intensive NLP Tasks", NeurIPS 2020. arXiv:2005.11401.

핵심 용어 4개

embedding model임베딩 모델

"텍스트를 768-dim 같은 고차원 벡터로 변환"하는 모델 (예: BGE-M3, E5). 비슷한 의미의 텍스트는 비슷한 벡터로.

vector DB벡터 데이터베이스

사내 문서들의 임베딩 벡터를 저장. 코사인 유사도 기반 검색이 빠름. Pinecone · Weaviate · Milvus · pgvector 등.

cosine similarity코사인 유사도

두 벡터 사이의 각도. -1 ~ 1 범위. 1에 가까울수록 비슷. 검색은 "질문 임베딩과 가장 유사한 top-K 문서" 반환.

context injection컨텍스트 주입

검색된 top-K 문서를 LLM의 입력 prompt에 포함시키는 것. "[문서들] 위 정보를 바탕으로 답하시오: [질문]"

RAG 4단계 흐름 1. Embed query: q_emb = embed("FMM 정렬 오차 원인은?") ← 768-dim 벡터 2. Vector DB search: top_K = argmax_d cosine(q_emb, d_emb) ← 유사도 top-3 3. Context injection: prompt = top_K 문서 + 질문 ← LLM 입력 4. LLM generation: answer = LLM(prompt) ← token 스트리밍 핵심 효과: 환각 방지 + 출처 인용 가능 + 자료 업데이트 즉시 반영
SIMULATION · 데모 사용법
  1. 질문 선택에서 fab 관련 3가지 질문 중 하나 선택 (예: "FMM 정렬 오차 원인은?").
  2. 맨 위에 노란 박스로 질문이 표시되고, 오른쪽에 768-dim 임베딩 벡터가 24개 막대로 시각화됩니다.
  3. ① Retrieve 버튼 — 8개 사내 문서(SOP/ECN/8D)에 대해 코사인 유사도 계산. Top-3 문서가 초록으로 강조되고 유사도 점수가 막대로 표시됩니다.
  4. 중앙 보라색 박스에 컨텍스트 주입 prompt가 표시 — "[Context] top-3 IDs · [Question] 질문..." 형식.
  5. ② Generate 버튼 — LLM이 토큰을 한 개씩 스트리밍으로 생성. 답변 끝에 출처 인용(SOP-EV-021 등)이 자동 포함.
  6. 토큰 생성 중간에는 빨간 커서가 깜빡이며 "지금 어디까지 생성됐는지" 표시.
