1
FOUNDATIONAL · 1986 · Rumelhart, Hinton, Williams

신경망 + 역전파 — 모든 딥러닝의 출발점

"어떻게 컴퓨터가 데이터로부터 함수를 자동으로 학습할 수 있는가?" 이 질문에 대한 1986년의 답이 오늘날 GPT, ChatGPT, 자율주행을 모두 가능하게 만든 핵심 알고리즘입니다.

WHY · 왜 만들어졌나

1986년 이전: "신경망 학습 불가능론"이 있었다

1958년 Rosenblatt의 Perceptron은 한 층짜리 신경망으로, XOR 같은 비선형 문제를 풀 수 없다는 한계가 1969년 Minsky에 의해 증명됐습니다(Perceptrons 저서). 이 발표 후 약 15년간 신경망 연구는 '겨울'을 맞았습니다. 여러 층으로 쌓으면 표현력은 늘지만 — "각 층의 가중치를 어떻게 동시에 학습시킬 것인가?"가 풀리지 않은 문제였습니다.

1986년 Rumelhart, Hinton, Williams의 Nature 논문이 이 문제를 풀었습니다. 핵심 아이디어 — "미분의 chain rule을 출력에서 입력 방향으로 거꾸로 적용해 모든 가중치의 기울기를 한 번에 계산" — 이것이 backpropagation(역전파)입니다.

Rumelhart, Hinton, Williams (1986). "Learning representations by back-propagating errors", Nature 323, 533-536.

핵심 용어 4개

weight (w)가중치

한 뉴런이 다른 뉴런으로부터 받는 입력의 "중요도". 학습 = 모든 가중치를 데이터로 자동 조정. 신경망에는 수억~수조 개의 w가 존재.

loss (L)손실

예측 ŷ과 정답 y의 차이를 수치화. L = (ŷ - y)² 같은 형태. 학습의 목표는 L을 최소화하는 것.

gradient (∂L/∂w)기울기

"이 가중치 w를 살짝 늘리면 손실 L이 얼마나 변하는가?"의 미분값. 이 값의 반대 방향으로 w를 움직이면 손실이 감소.

learning rate (η)학습률

w를 얼마나 큰 폭으로 조정할지의 step size. 너무 크면 발산, 너무 작으면 학습이 안 됨. 보통 0.001~0.1.

학습 한 step의 수식 1. forward pass: ŷ = f(x; W) ← 현재 W로 예측 2. loss 계산: L = (ŷ - y)² ← 예측과 정답의 차이 3. backprop: ∂L/∂W = chain rule ← 모든 w의 기울기 한 번에 4. update: W_new = W − η · ∂L/∂W ← 기울기 반대 방향으로 이동
SIMULATION · 데모 사용법
  1. FORWARD를 누르면 입력 x가 가중치를 곱해 가며 출력 ŷ까지 흘러갑니다 — 노드 색이 진해질수록 활성값이 높음.
  2. BACKWARD를 누르면 손실 L의 기울기가 출력 → 입력 방향으로 거꾸로 흘러, 각 가중치 옆에 Δ값이 표시됩니다 (이게 ∂L/∂w).
  3. UPDATE를 누르면 모든 가중치가 w ← w − η·Δ 만큼 조정됩니다 (선 굵기·색이 살짝 변함).
  4. 다시 FORWARD를 누르면 새 가중치로 손실이 더 작아진 것을 확인할 수 있습니다 — 이게 학습 한 사이클.
  5. 자동학습 10회로 사이클이 자동 반복되며 손실이 점진적으로 줄어드는 것을 확인하세요.
2 → 3 → 1 신경망 — Forward / Backward / Update 한 사이클
목표 y 0.80
학습률 η 1.0
FORWARD 버튼을 눌러 한 단계씩 진행하세요.
노드 색 = 현재 활성값(진할수록 큼). 연결선 굵기 = |w|, 색 = 부호(파랑+/빨강−). BACKWARD 후 각 w 옆 빨간 Δ값이 기울기.
INDUSTRY · 산업 적용

fab AI의 모든 학습은 이 사이클의 변형

CNN(결함 분류), Transformer(VM 회귀), LSTM(시계열) 모두 가중치 수억 개로 늘어났을 뿐 학습 사이클은 FORWARD → BACKWARD → UPDATE로 동일합니다. PyTorch의 loss.backward() 한 줄이 backprop을, optimizer.step()이 update를 처리합니다.

2
FOUNDATIONAL · 1998 LeNet (LeCun) · 2015 ResNet (He et al.)

CNN — 이미지를 "작은 필터의 슬라이딩"으로 본다

이미지 인식·결함 검사·자율주행 vision의 표준 알고리즘. 핵심 아이디어는 단 하나 — "같은 작은 필터를 모든 위치에 슬라이딩하며 패턴을 찾는다". 가중치 공유와 국소성이 결합된 강력한 inductive bias.

WHY · 왜 만들어졌나

1998년 이전: 일반 신경망은 이미지에 비효율적이었다

100×100 흑백 이미지를 일반 신경망에 넣으면 입력 노드가 10,000개. 다음 층이 100 노드라면 가중치만 100만 개 — 학습이 너무 어렵습니다. 그리고 같은 모양(예: 가로 에지)이 위치만 달라져도 완전히 다른 입력으로 인식되는 구조적 비효율이 있습니다.

LeCun의 1998년 LeNet-5는 두 가지 인사이트를 도입했습니다 — ① 국소성 (locality): 픽셀 한 점은 주변 픽셀과만 의미 있게 연관. ② 가중치 공유 (weight sharing): 같은 작은 필터를 이미지 전체에 슬라이딩. 100만 개 가중치가 9개로 압축되면서 학습이 가능해졌습니다.

2015년 He의 ResNet은 skip connection (y = F(x) + x)으로 152층 깊이의 학습을 가능하게 만들어, ImageNet 인간 수준 성능을 달성. 오늘날 fab의 ADC, KLA Multi-Perspective, Applied ExtractAI 모두 ResNet 또는 그 후예(ConvNeXt, DINOv2)를 백본으로 사용.

LeCun et al. (1998). "Gradient-based learning applied to document recognition", Proc. IEEE. / He et al. (2015). "Deep Residual Learning", arXiv:1512.03385.

핵심 용어 4개

kernel (filter)필터

3×3, 5×5 같은 작은 행렬. 9개의 가중치 = 한 종류의 패턴 검출기. 학습으로 자동 발견됨 (예: 가로 에지, 세로 에지, 대각선).

stride보폭

필터를 한 번에 몇 픽셀씩 이동시킬지. stride=1은 한 칸씩, stride=2는 두 칸씩. 출력 크기와 receptive field 결정.

feature map특징 지도

필터를 슬라이딩해 만든 출력. "이 필터의 패턴이 이미지 어디에 얼마나 강하게 있는가"의 지도. 다음 층의 입력이 됨.

receptive field수용 영역

"이 한 출력 픽셀이 원본 이미지의 어느 영역을 봤는가". 층이 깊어질수록 receptive field가 커져 더 큰 패턴을 인식.

합성곱 1 위치 계산 y[i,j] = Σ_m Σ_n x[i+m, j+n] · K[m,n] + b (3×3 영역 합성곱 = 9개 곱한 후 합 + bias) → 이 같은 K를 모든 (i,j) 위치에 슬라이딩 = 가중치 공유 → 깊이 쌓아 ResNet 152층, ConvNeXt 등으로 확장
SIMULATION · 데모 사용법
  1. 왼쪽 8×8 입력에는 십자 모양 패턴(0.9 값)이 있고, 가운데 작은 3×3이 학습된 필터입니다.
  2. 커널 선택에서 "수평 에지", "수직 에지", "Sobel" 등으로 다른 패턴 검출기를 골라보세요. 필터 값이 −1/0/+1로 변하며 각각 다른 종류의 에지를 검출합니다.
  3. 한 스텝 슬라이딩을 누르면 노란색 테두리(현재 보고 있는 3×3 영역)가 한 칸 이동하며, 우측 6×6 feature map의 해당 칸이 채워집니다.
  4. 각 칸의 값은 "이 위치에서 필터의 패턴이 얼마나 강하게 발견됐는가"를 의미. 큰 값 = 패턴 강한 검출.
  5. 같은 필터(가중치 9개)가 모든 36개 위치에 동일하게 적용 — 이게 가중치 공유의 의미입니다.

3
FOUNDATIONAL · 2017 · Vaswani et al. (Google Brain)

Transformer Attention — "검색 엔진"으로 토큰 사이의 관계를 학습

GPT, ChatGPT, BERT, ViT, PatchTST 모두 이 단순한 메커니즘에서 출발. "한 토큰이 다른 모든 토큰을 동시에 본다"는 아이디어가 NLP뿐 아니라 비전·시계열까지 통합한 결정적 발명.

WHY · 왜 만들어졌나

2017년 이전: RNN·LSTM은 긴 문장에서 정보를 잃었다

"The cat that the dog chased was hungry"라는 문장에서 "was"의 주어는 "cat"입니다. RNN은 단어를 순서대로 읽으며 마지막에 도달할 때쯤 앞부분 정보가 흐려지는(vanishing gradient) 문제가 있었습니다. LSTM이 게이트로 일부 완화했지만 근본적 한계는 남아 있었습니다.

2017년 Google Brain 팀이 발표한 "Attention is All You Need"는 RNN의 순차 처리를 완전히 버리고, 모든 토큰이 동시에 모든 다른 토큰을 보는 Self-Attention 메커니즘만으로 모든 의존 관계를 학습할 수 있음을 증명했습니다. 이 단순한 아이디어가 NLP를 넘어 ViT(이미지), PatchTST(시계열), AlphaFold(단백질)까지 모든 현대 AI의 토대가 됐습니다.

Vaswani et al. (2017). "Attention Is All You Need", NeurIPS 2017. arXiv:1706.03762.

핵심 용어 — Q · K · V (검색 엔진 비유)

Attention을 가장 쉽게 이해하는 방법은 "도서관 검색" 비유입니다.

Query (Q)질의

"내가 찾고 싶은 것". 도서관에서 "야구 관련 책"이라고 검색하는 것과 같음. 한 토큰이 다른 토큰들에게 던지는 질문.

Key (K)키워드

"각 책의 색인 카드". Query와 비교해 얼마나 관련 있는지를 판단하는 기준. Q와 모든 K의 내적으로 유사도 점수 계산.

Value (V)실제 내용

"책 안의 진짜 내용". 유사도 점수로 가중평균해서 최종 답을 만듦. 결과적으로 "관련 있는 토큰의 정보를 더 많이 가져오는" 효과.

Multi-Head다중 헤드

Q/K/V를 여러 종류로 동시에 만들어 각각 다른 관계를 학습. 한 head는 주어-동사, 다른 head는 형용사-명사 같은 다른 패턴을 잡음.

Self-Attention 핵심 수식 Attention(Q, K, V) = softmax( Q·Kᵀ / √dₖ ) · V Step 1: Q·Kᵀ → 모든 토큰 쌍의 유사도 행렬 (n × n) Step 2: ÷ √dₖ → 안정화 (큰 값 방지) Step 3: softmax → 행 합이 1인 확률 분포로 정규화 Step 4: · V → 가중평균으로 새 토큰 표현 계산

용어 풀이 — Q (Query): 지금 내가 정보를 "찾고 싶은" 토큰의 표현 · K (Key): 다른 토큰들이 "내가 누구인지" 광고하는 표현 · V (Value): 실제로 가져올 정보 · softmax: 여러 점수를 합이 1인 확률 분포로 변환하는 함수 · √dₖ: 벡터 차원의 제곱근 (큰 차원에서 dot product가 너무 커지는 것 방지)

SIMULATION · 데모 사용법
  1. 예시 문장 "the cat sat on the mat"에서 한 토큰을 클릭해 보세요. 그 토큰이 Query 역할을 합니다.
  2. 아래 막대그래프가 그 Query가 6개 Key 토큰 각각에 얼마나 attention을 주는지 보여줍니다 (합이 1).
  3. 토큰 사이의 곡선 화살표 굵기도 attention 가중치를 표현합니다.
  4. Head 선택으로 다른 attention 패턴(구문 관계 / 장거리 의존 / 인접 관계)을 비교해 보세요.
  5. 오른쪽 6×6 행렬은 전체 attention 행렬입니다. 한 행 = 한 토큰의 분포.

4
FOUNDATIONAL · 1997 · Hochreiter & Schmidhuber

LSTM — 게이트로 "기억할지 말지"를 학습한다

Transformer 이전 시계열의 표준. 오늘날 양산 fab의 시계열 모델 다수가 여전히 LSTM 기반 (전환에는 검증 비용이 들기 때문). SK hynix Panoptes VM의 1세대 베이스라인도 LSTM이었습니다.

WHY · 왜 만들어졌나

1997년 이전: RNN은 긴 시퀀스에서 학습이 안 됐다

RNN은 시퀀스를 순서대로 처리하며 이전 정보를 다음으로 전달합니다. 그런데 역전파 시 기울기가 순차 곱셈으로 전달되면서 — vanishing gradient (기울기 소실): 0.5의 100 거듭제곱은 약 8×10⁻³¹ (거의 0) — 또는 exploding gradient (기울기 폭발): 1.5의 100 거듭제곱은 약 4×10¹⁷ (400경 단위) — 문제가 발생했습니다. 결과적으로 RNN은 20-30 step 이상의 의존 관계를 학습할 수 없었습니다.

Hochreiter (당시 박사과정생)와 지도교수 Schmidhuber가 1997년 LSTM을 제안. 핵심 아이디어 — "각 시점에서 무엇을 잊을지 / 무엇을 받을지 / 무엇을 내보낼지"를 게이트로 학습. 이 게이트들이 vanishing gradient를 우회해, 100+ step 의존 관계가 가능해졌습니다. 이 발명으로 음성 인식, 번역, 시계열 예측이 폭발적으로 발전했습니다.

Hochreiter & Schmidhuber (1997). "Long Short-Term Memory", Neural Computation 9(8).

핵심 용어 — 3개 게이트 + cell state

forget gate (f_t)망각 게이트

"이전 cell state c_{t-1}에서 무엇을 잊을지" 결정. 0~1 값. 0이면 완전히 잊고, 1이면 그대로 보존. f_t = σ(W_f · [h_{t-1}, x_t] + b_f)

input gate (i_t)입력 게이트

"새 입력 x_t에서 무엇을 받을지" 결정. 0~1 값. 0이면 입력 무시, 1이면 모두 받음. 새 정보의 흐름을 통제.

output gate (o_t)출력 게이트

"현재 cell state c_t에서 무엇을 외부로 내보낼지" 결정. 셀의 내부 상태와 출력을 분리하는 메커니즘.

cell state (c_t)셀 상태 = 장기 기억

시간을 가로질러 흐르는 "장기 기억 conveyor belt". 게이트들이 이 위에 정보를 쓰고 지움. c_t = f_t·c_{t-1} + i_t·x̃_t

LSTM 한 step의 4개 핵심 수식 f_t = σ(W_f · [h_{t-1}, x_t] + b_f) ← 망각 게이트 (얼마나 잊을지) i_t = σ(W_i · [h_{t-1}, x_t] + b_i) ← 입력 게이트 (얼마나 받을지) o_t = σ(W_o · [h_{t-1}, x_t] + b_o) ← 출력 게이트 (얼마나 내보낼지) c_t = f_t · c_{t-1} + i_t · tanh(W_c·…) ← 셀 상태 갱신 h_t = o_t · tanh(c_t) ← 외부 출력
SIMULATION · 데모 사용법
  1. 시퀀스 선택에서 "괄호 균형 ( ( a ) b )" 같은 입력을 골라 보세요.
  2. 다음 시점 → 버튼으로 한 step씩 진행. 입력 토큰이 LSTM에 들어가면서 3개 게이트가 0~1 값으로 열리고 닫힙니다.
  3. "여는 괄호 ("를 받으면 input gate가 크게 열려 cell state가 +1로 올라가고 (괄호 깊이 증가).
  4. "닫는 괄호 )"를 받으면 forget gate가 절반으로 줄어 cell state가 −1 차감됩니다.
  5. 하단의 cell state c_t와 hidden state h_t의 막대그래프가 시간을 따라 누적되며, 게이트가 어떻게 장기 기억을 조절하는지 시각화됩니다.
  6. 마지막 ")"를 받았을 때 c_t ≈ 0이면 괄호가 균형을 이뤘다는 의미.
LSTM 셀의 게이트 동작 — 시간을 따라 무엇이 어떻게 흐르는가
시퀀스
"다음 시점" 버튼으로 한 step씩 진행하세요.
상단=입력 시퀀스(현재 강조). 중앙=LSTM 셀 (3 게이트 + c_t). 하단=시간별 c_t와 h_t.
