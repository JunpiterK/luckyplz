사례에서 도출된 패턴

16건 사례 횡단 — 5가지 공통 패턴

회사·공정·국가가 다른 16개 사례를 한 표로 모았을 때 드러나는 반복 패턴입니다.

PATTERN 1

"섀도우 배포 → 점진 승격"이 양산 진입 표준

SK hynix Panoptes · Intel n-i to n · LG Display Mura RL — 모두 처음에는 추천만 출력하는 섀도우 모드로 시작해 검증 후 단계적 승격. RL · VM · APC 모두 동일.

PATTERN 2

사전학습 백본 + Last-Layer 미세조정 = 사실상 표준

DINOv2 · ResNet · Transformer trunk를 동결하고 도메인별 head만 학습. Intel ADC · Applied ExtractAI · KLA Multi-Perspective 모두 같은 패턴.

PATTERN 3

불확실성 정량화 없는 VM은 APC에 못 쓴다

Bayesian Last-Layer · Heteroscedastic loss · Deep Ensemble 셋 중 하나는 필수. Panoptes의 −29% variability도 이 위에 서 있음.

PATTERN 4

LLM은 RAG + 온프렘 + 사인오프가 양산 골격

Micron · BOE · CSOT · Samsung Display 모두 동일 — IP 보안 위해 온프렘 배포, 환각 방지 위해 RAG 필수, 자동 행동은 엔지니어 사인오프 게이트.

PATTERN 5

CNN이 아직도 fab AI의 진입점

16건 중 13건이 CNN을 핵심 또는 보조로 사용. 검사가 가장 빠른 ROI를 만들고 그 위에 시계열 · LLM · RL이 단계적으로 얹힘. ConvNeXt → DINOv2 진화도 그대로.
