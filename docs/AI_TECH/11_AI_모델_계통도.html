★ 시대를 대표한 King 모델

📊 한 페이지 전체 계통도 — 9 패밀리 × 40년

시간 축은 왼쪽에서 오른쪽으로 흐릅니다(1986 → 2026). 각 패밀리는 행으로 분리되며, 화살표는 "직접 영감을 받은 후속" 관계를 나타냅니다. ★는 각 시대의 King 모델.

※ 보기: 가로 스크롤 가능. ★ 표시는 각 시기 King 모델. 점선 화살표는 패밀리 간 영향(예: Transformer → ViT). 실선 화살표는 같은 패밀리 내 직접 후속.

👑 시대별 King 모델 — "그 시기를 정의한 한 모델"

각 시기에 가장 큰 영향을 미친 한 모델을 정리합니다. 이 모델들이 다음 시대의 출발점이 됩니다.

1986

Backpropagation

Rumelhart · Hinton · Williams · Nature

"신경망에 어떻게 학습시키나"의 답. 미분의 chain rule을 거꾸로 적용해 모든 가중치 기울기를 한 번에 계산.

유산: 40년 후에도 모든 신경망이 이걸 쓴다. 변하지 않은 토대.
1997

LSTM

Hochreiter · Schmidhuber

RNN의 vanishing gradient 문제를 게이트(forget · input · output)로 해결. 100+ step 의존 관계 학습 가능.

유산: 2014~2017 음성·번역 황금기 만듦. 2017 Transformer 등장 후 빠르게 대체됨.
2012

AlexNet

Krizhevsky · Sutskever · Hinton

ImageNet 대회 25% → 16% 오차로 반전. 딥러닝 부흥의 시작점. GPU(GTX 580 2개)로 학습.

유산: 모든 vision DL의 출발. 이전엔 SVM/HOG 시대 → 이후 CNN 시대.
2014

GAN

Goodfellow et al.

Generator vs Discriminator의 적대적 게임으로 이미지 생성. "AI가 가짜 이미지를 진짜처럼 만든다"는 시대 개막.

유산: StyleGAN까지 8년 황금기. 2020 Diffusion 등장 후 바통 넘김.
2014

XGBoost

Chen · Guestrin (KDD 2016)

Gradient Boosted Trees의 산업 수준 구현. Kaggle 대회 압도. 2026년 현재까지 표 데이터 표준.

유산: 12년째 dominant. fab 수율 예측·RCA의 사실상 default 도구.
2015

ResNet

He · Zhang · Ren · Sun (Microsoft)

"Skip connection"으로 152층 신경망 학습 가능. 깊을수록 잘 안 되던 문제(degradation) 해결.

유산: 모든 후속 vision 모델이 skip connection 사용 (Transformer · ConvNeXt · ViT 모두).
2017

Transformer

Vaswani et al. · Google · "Attention is All You Need"

RNN/CNN을 모두 버리고 attention만으로 시퀀스 학습. 역대 가장 영향력 큰 AI 논문.

유산: 9년째 모든 패밀리(언어·비전·시계열·그래프·멀티모달)의 토대. 2026 현재 dominant.
2018

BERT

Devlin et al. · Google

Transformer encoder + masked LM 사전학습 → 모든 NLP 태스크 SOTA. "사전학습 + fine-tuning"의 시대 개막.

유산: NLP가 "각 태스크별 모델"에서 "거대 모델 fine-tune"으로 패러다임 전환.
2020

GPT-3

OpenAI · Brown et al.

175B 파라미터 + in-context learning. 예시만 보여주면 학습 없이 새 태스크 수행. "규모가 곧 능력"의 시대 시작.

유산: 모든 LLM이 이 path 따름. ChatGPT 직접 부모.
2020

DDPM (Diffusion)

Ho · Jain · Abbeel · UC Berkeley

노이즈 → 이미지의 reverse process를 신경망으로 학습. GAN보다 안정적이고 다양성 높음.

유산: 2년 후 Stable Diffusion · DALL-E · Midjourney 폭발의 토대. 2024 Sora도 이 변형.
2020

ViT

Dosovitskiy et al. · Google

이미지를 patch로 잘라서 Transformer에 넣음. CNN 없이 vision SOTA. "이미지도 sequence다"

유산: Swin · DINOv2 · SAM의 직접 부모. 학술 vision은 이제 ViT 계열로 이전.
2021

CLIP

Radford et al. · OpenAI

이미지와 텍스트를 같은 임베딩 공간에 매핑. "사진을 자연어로 검색"이 가능해짐.

유산: Stable Diffusion의 텍스트 조건, GPT-4V·Gemini 멀티모달, 모든 VLM의 토대.
2022

Stable Diffusion

Stability AI · CompVis · Rombach et al.

Latent space에서 diffusion 수행 → 일반 GPU에서도 생성 가능. 이미지 생성 대중화의 시작점.

유산: SDXL · FLUX · 모든 오픈소스 이미지 생성. 산업 합성 데이터 도구의 표준.
2022

ChatGPT

OpenAI · GPT-3.5 + RLHF

대화형 인터페이스 + RLHF로 유용성 극대화. 출시 5일 만에 100만 명, 2개월 만에 1억 명. 역대 가장 빠른 사용자 확산.

유산: "AI가 사람과 대화한다"는 경험을 대중화. 모든 LLM 회사가 이 패턴 따라옴.
2023

GPT-4

OpenAI

추정 1.7~1.8T MoE 구조. 미국 변호사 시험 상위 10%, 코딩·수학 능력 폭발. multimodal 대응.

유산: Llama 2/3, Claude 3, Gemini 모두 GPT-4 따라잡기 위해 진화.
2024

GPT-4o · Claude 3.5 Sonnet

OpenAI · Anthropic

Native 멀티모달(이미지·음성 동시 처리) + 비용 절반. Claude 3.5는 코딩·수학에서 GPT-4 추월.

유산: "거대 frontier 모델 + 효율적 mid-tier" 양극화 구조 정착.
2024

Llama 3.1 405B

Meta

오픈웨이트 모델이 처음으로 GPT-4 수준 도달. 16,000 H100으로 학습. 사내 deploy의 새 표준.

유산: 사내 LLM 운영 (Micron · Samsung Display 등) 가능하게 만든 결정적 모델.
2024

Sora · Veo 2

OpenAI · Google DeepMind

1분짜리 고해상도 비디오를 텍스트만으로 생성. Diffusion + Transformer 결합 (DiT).

유산: 콘텐츠 산업의 새 시대. 광고 · 영화 · 교육 영상 제작 변혁 진행 중.
2024-2025

OpenAI o1 · DeepSeek-R1

OpenAI · DeepSeek

"답하기 전에 생각" — internal Chain-of-Thought + RL로 학습. 수학·과학 능력 점프. R1은 오픈웨이트 + GRPO 알고리즘 공개.

유산: "추론 모델" 시대 개막. 2025년 모든 frontier 모델이 reasoning 능력 강화.

🌳 9 패밀리 deep dive — 각 가족의 진화 한 줄

각 패밀리의 출발점부터 현재(2026)까지 직계 후손을 정리합니다. ★ 현재 표시는 2026년 현재 가장 hot한 모델.

① Vision · CNN

합성곱 신경망
LeNet (1998) → AlexNet (2012) → VGG · GoogLeNet (2014) → ResNet (2015) → DenseNet (2017) → EfficientNet (2019) → ConvNeXt (2022) → ConvNeXt V2 / YOLO v10 (2024 ★)
대표 사례: Applied Materials ExtractAI · KLA Klarity · BOE B8 YOLOv7 · TCL CSOT 1세대 ADC. fab 산업 검사의 압도적 표준 — 학술은 ViT로 이전했지만 산업은 여전히 CNN 다수.

② Vision · Transformer

ViT 계열
ViT (2020) → Swin (2021) → CLIP (2021) → MAE (2021) → DINOv2 (2023) → SAM (2023) → SAM 2 (2024) → Florence-2 (2024 ★)
대표 사례: Applied Materials DINOv2 임베딩 · KLA · ASML Holistic Patterning. 학술 vision은 이미 ViT/DINOv2 시대. 산업 도입은 진행 중.

③ Language · Decoder LLM

GPT 가족
Transformer (2017) → GPT-1/2/3 (2018-2020) → InstructGPT (2022) → ChatGPT (2022) → GPT-4 (2023) → GPT-4o · Claude 3.5 · Llama 3.1 (2024) → DeepSeek-R1 · Claude 4 · GPT-5 reasoning 모델 (2025 ★)
대표 사례: Samsung Display Watson+EDM · Micron Engineer Co-pilot · NVIDIA ChipNeMo · Synopsys.ai. 모든 사내 코파일럿의 기반.

④ Time Series

시계열 예측
ARIMA (1970s) → LSTM (1997) → Prophet · DeepAR (2017) → Informer (2021) → PatchTST (2023) → iTransformer · TimesFM · Mamba · Chronos (2024) → TimesFM 2 · Time-MoE (2024-25 ★)
대표 사례: SK hynix × Gauss Labs Panoptes VM · Tokyo Electron InVia · 1세대 fab VM 대다수. VM의 실제 deploy는 여전히 LSTM+XGBoost 다수, PatchTST는 도입 검토.

⑤ Generation

VAE/GAN/Diffusion
VAE (2013) → GAN (2014) → DCGAN (2015) → StyleGAN (2018) → DDPM (2020) → Stable Diffusion (2022) → SDXL (2023) → Sora · FLUX · Veo 2 (2024) → Sora 2 · Veo 3 · DiT scale-up (2025 ★)
대표 사례: ASML EUV stochastic 모델링 · NVIDIA cuLitho · Samsung Generative Defect Synthesis. fab 합성 데이터 영역에서 도입 시작.

⑥ Reinforcement Learning

제어 · 정렬
Q-learning (1989) → DQN (2013) → AlphaGo (2016) → PPO (2017) → SAC · AlphaZero (2018) → AlphaTensor (2022) → RLHF (2022) → DPO (2023) → GRPO (2024) → o1/R1 reasoning RL (2024-25 ★)
대표 사례: Google DeepMind 데이터센터 냉각 · Anthropic RLHF · OpenAI o1/o3 · AlphaTensor. fab deploy는 제한적, LLM 정렬·추론 학습이 현재 핵심 영역.

⑦ Tabular · Tree

표 데이터 표준
Decision Tree (1980s) → Random Forest (2001) → Gradient Boosting (1999) → XGBoost (2014) → LightGBM (2017) → CatBoost · SHAP (2017-18) → TabNet · TabTransformer (2019-20) → TabPFN · XGBoost 2.x (2023-25 ★ — 여전히 표준)
대표 사례: Intel n-i to n APC · Bosch · Samsung Memory · 거의 모든 fab 데이터팀. 2014~2026 12년간 표 데이터의 절대 표준 — 변하지 않음.

⑧ Graph Neural Networks

관계 학습
Node2Vec (2016) → GCN (2017) → GraphSAGE · GAT (2017-18) → HGT (2020) → AlphaFold (2021) → Graph Transformer · GPS (2023-24 ★)
대표 사례: TSMC HGT (수율 RCA · IEDM 2022/23) · DeepMind AlphaFold · Google/Facebook 추천. 학술적 발달은 빠르나 산업 deploy는 매우 제한적.

⑨ Anomaly Detection

라벨없는 결함 검출
Isolation Forest (2008) → Autoencoder (2014) → Deep SVDD (2018) → PaDiM (2020) → FastFlow (2021) → PatchCore (2022) → WinCLIP · AnomalyCLIP (2023) → EfficientAD (2024 ★) · ReConPatch
대표 사례: LG Display Mura 검출 · Samsung Display 미세 Mura · Bosch automotive 센서. MVTec AD 벤치마크 표준 — fab 양품 학습 anomaly의 deploy 표준.

⑩ Multimodal · Robot VLA

비전+언어+행동
CLIP (2021) → Flamingo (2022) → BLIP-2 · LLaVA (2023) → GPT-4V (2023) → RT-1/RT-2 (2022-23) → GPT-4o · Gemini 1.5 (2024) → π0 · OpenVLA (2024) → Gemini 2.5 · Helix · π0.5 (2025 ★)
대표 사례: Figure 02 (OpenAI 협업) · 1X NEO · Tesla Optimus · Boston Dynamics Atlas. 2024년부터 휴머노이드 로봇이 본격적 산업 도입 단계.

💡 40년 흐름의 5가지 핵심 통찰

계통도 전체에서 자주 보이지 않지만 중요한 큰 흐름들입니다.

INSIGHT 1

"Transformer가 모든 것을 통일했다"

2017년 Transformer 발표 후 9년이 지났는데, 비전·언어·시계열·그래프·멀티모달 거의 모든 패밀리가 Transformer 변형으로 수렴. "한 아키텍처로 모든 데이터"가 현실이 됨.

INSIGHT 2

"규모(Scale)가 곧 능력"

GPT-2 (1.5B) → GPT-3 (175B) → GPT-4 (1.8T) — 큰 모델이 작은 모델로는 풀리지 않던 문제를 풀어냄. Emergent ability가 핵심 발견. 단, 비용도 같이 폭발 ($100M+ 학습).

INSIGHT 3

"오래된 토대는 변하지 않는다"

Backprop (1986) 40년째, XGBoost (2014) 12년째 dominant. 화려한 신모델이 매년 나오지만, 토대는 안정적. fab 양산은 토대 모델로 운영되고, 신모델은 검토 단계.

INSIGHT 4

"오픈소스가 빠르게 frontier 따라잡는다"

Llama 1 (2023.02 · GPT-3 수준) → Llama 3.1 (2024.07 · GPT-4 수준) → DeepSeek-R1 (2025.01 · o1 수준). 오픈 vs 폐쇄 격차가 6개월~1년으로 좁혀짐. 사내 deploy 가능성 폭발.

INSIGHT 5

"학술 SOTA → 산업 양산까지 평균 3-5년"

Transformer (2017) → fab VM 도입 (2022~) · ResNet (2015) → AOI 표준 (2018~) · Diffusion (2020) → 결함 합성 (2024~). 새 알고리즘 발표 직후가 아니라 3-5년 후가 fab 적용 시점. 지금 학술 SOTA(o1·R1·Mamba)는 2027~2029 산업 표준 후보.

INSIGHT 6

"한국·중국이 학술→산업 격차를 좁히고 있다"

SK hynix Panoptes(2022~) · Samsung Hyper-Auto Fab(2024~) · BOE Blue Whale(2023~) · DeepSeek-R1(2025) · Qwen 시리즈. 미국 중심 학술 발표 → 동아시아 fab 적용이 빠르게 진행.
