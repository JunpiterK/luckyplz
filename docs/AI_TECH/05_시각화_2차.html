AI × FAB · 시각화 학습 — 2차 (전면 개편판)

현대 산업 응용 4종 — 원조 알고리즘 deep divePatchTST · Q-learning · Bayesian Optimization · Diffusion

2차 배치는 fab 산업이 마주치는 4가지 핵심 문제(시계열 예측 · 자동 제어 · 최적 탐색 · 데이터 생성)에 대한 최신 학술 알고리즘 4종을 다룹니다. PatchTST는 시계열 Transformer의 SOTA(2023~), Q-learning은 강화학습 교과서의 출발점, Bayesian Optimization은 적은 시행으로 최적값을 찾는 표준, Diffusion은 생성 모델의 현재 SOTA(2020~)입니다. 각 데모마다 (1) 왜 만들어졌는지의 역사적 배경, (2) 핵심 용어 4개, (3) 수식, (4) 시뮬레이션 사용법, (5) 인터랙티브 데모, (6) 실제 fab 적용 영역까지 정리합니다.

⚠ 중요 — "산업 직결"이 의미하는 것의 정직 검증

이 4종은 "현재 fab에서 가장 많이 deploy된 알고리즘"이 아니라 "fab의 4가지 문제 영역(예측·제어·탐색·생성)을 대표하는 학술 알고리즘"입니다. 실제 양산 deployment 빈도 기준 top 4는 ① XGBoost/GBT (수율·RCA), ② CNN/ResNet (검사), ③ LSTM/Transformer 시계열 (VM), ④ PatchCore (anomaly)이며, 이는 04번(CNN·LSTM)과 06번(GBT·PatchCore)에서 다룹니다.
05번의 4종은 "신흥 · SOTA · 도입 검토 단계"에 가까우며, Q-learning은 RL의 교과서적 출발점(현대 산업 RL은 PPO·SAC·CQL이 표준), BO는 특수 상황(소량 시험)에서 강함, Diffusion은 합성 데이터 생성 영역에서 부상 중입니다. 학습 가치는 매우 높지만 "현재 표준 도구"는 아닙니다.

🎯 비전문가를 위한 가이드 — fab 운영자가 매일 마주치는 4가지 문제

"이 4가지는 fab의 4가지 문제 영역(예측·제어·탐색·생성)을 대표"

1차 시각화(04번)가 "AI 자체의 기본 원리"였다면, 2차는 fab의 4가지 문제 영역을 대표하는 학술 SOTA 알고리즘 4종입니다. 이들이 곧 "현재 가장 많이 쓰이는 도구"는 아닙니다(실제 deployment 1위는 영역별로 GBT·CNN·LSTM·PatchCore — 04·06번 참조). 각 시뮬레이션이 어떤 일상 상황을 컴퓨터로 옮긴 것인지 먼저 보시면, 시뮬레이션 결과를 어떻게 해석해야 하는지 직관이 잡힙니다.

⑤
PatchTST
"내일 무슨 일이 일어날까"
💡 일상 비유
의사가 환자의 일주일 체온 기록을 보고 내일 체온 예측: 한 시간 단위가 아니라 "오전·오후·저녁" 같은 작은 조각(patch)으로 나눠 패턴 파악. 작은 흔들림은 무시하고, 큰 추세에 집중하는 방식.
🏭 fab 매핑
chamber 60초 trace → 다음 wafer CD/두께 예측: trace를 5초 짜리 patch 12개로 자르고, 각 patch에서 추세를 학습. 가상 계측(VM)의 현재 SOTA.
🎯 시뮬레이션에서 볼 것
"patch 크기"를 조절하면 — 작게 하면 미세 변동을 잡지만 노이즈에 흔들림 / 크게 하면 큰 추세는 잡지만 빠른 변화 놓침. 이 trade-off가 모든 VM 모델 설계의 핵심.
⑥
강화학습 (Q-learning)
"시행착오로 자동 제어 익히기"
💡 일상 비유
아이가 자전거 배우기: 처음엔 무작위로 페달질 → 넘어지면 −1, 잘 가면 +1. 100번 시도하면 "지금 상태(state)면 어떻게 페달(action)을 밟아야 안 넘어진다"를 무의식적으로 학습.
🏭 fab 매핑
도가니 온도 자동 제어: 현재 두께 spec과 차이(state)에서 RF power를 얼마나 올릴지(action) 학습. spec 안 → +상, spec 밖 → −벌. 100만 번 시뮬레이션 후 양산 적용.
🎯 시뮬레이션에서 볼 것
"Q값" 셀이 점점 진해지는 것 = "이 상황에서 이 행동이 좋다"고 학습됨. 처음에는 무작위 색이었다가 결국 패턴이 명확해짐. "학습이 수렴했다"의 시각적 의미.
⑦
Bayesian Optimization
"최소 시행으로 최적 찾기"
💡 일상 비유
새 식당 점심 메뉴 결정하기: 100가지 메뉴를 다 먹어볼 수는 없음. 지금까지 시식한 결과를 토대로 "다음에 가장 맛있을 것 같은" 메뉴 1개만 시도. 보통 10~20번이면 가장 맛있는 메뉴 찾음.
🏭 fab 매핑
새 etch recipe 최적 조합 찾기: 압력·온도·RF·gas flow 4개 변수, 조합 1만 가지. 한 wafer 시험에 시간 30분. 무작정 다 못 함 → BO로 20~50번 시도에 최적값 도달.
🎯 시뮬레이션에서 볼 것
"acquisition function"이 다음에 시험할 점을 "좋은 영역 더 보기(exploitation)"와 "미지 영역 탐험(exploration)" 사이에서 균형 잡는 모습. 좋은 BO는 이 두 가지를 잘 섞음.
⑧
Diffusion (DDPM)
"노이즈에서 이미지 만들기"
💡 일상 비유
흐릿한 사진을 점점 선명하게 복원하는 사진 앱: 처음에 TV 잡음 같은 화면(완전 노이즈) → 100단계에 걸쳐 점점 형체가 드러남 → 마지막에 선명한 사진. 거꾸로 가는 영상 만들기.
🏭 fab 매핑
희귀 결함 영상 생성: 양산 라인에 "long-tail" 결함(드물게 나타나는 결함)이 1년에 10건이라 학습 데이터 부족 → Diffusion으로 비슷한 결함 영상 1만 장 합성 → ADC 모델 학습. ASML EUV stochastic 모델링도 같은 원리.
🎯 시뮬레이션에서 볼 것
노이즈 → 형체 → 명확 → 완성 4단계 변화. "학습 단계가 진행될수록 그림이 선명해지는 모습". 시작은 다 같지만 마지막은 다양한 결과가 나옴 = 데이터 다양성 확보.
🔗 4개 알고리즘이 fab에서 어떻게 함께 작동하나
① PatchTST(⑤)가 chamber FDC trace로 다음 wafer CD를 예측
② 예측이 spec 밖이면 RL(⑥)이 다음 wafer recipe를 자동 보정 (예: time -1.5초)
③ 새 제품 도입 시 BO(⑦)가 최적 recipe 조합을 20번 시험으로 찾아냄
④ 학습 데이터가 부족한 결함은 Diffusion(⑧)이 비슷한 영상 1만 장 합성해 ADC 학습 보조
→ 4가지가 모두 04번의 신경망 + Transformer 토대 위에 얹어진 응용입니다.

5
FOUNDATIONAL · 2023 · Nie, Nguyen, Sinthong, Kalagnanam (IBM Research)

PatchTST — 시계열을 "patch 토큰"으로 잘라 처리한다

2023년에 등장한 후 시계열 forecast의 패러다임이 바뀌었습니다. "긴 시퀀스를 그대로 Transformer에 넣지 말고 일정 길이 patch로 잘라 토큰화"하는 단순한 아이디어로 양산 배포 1순위 모델이 되었습니다. SK hynix Panoptes VM의 핵심 백본.

WHY · 왜 만들어졌나

2023년 이전: Transformer를 시계열에 그대로 쓰면 비효율적이었다

2017년 Transformer의 self-attention은 NLP에서 혁명적이었지만, 시계열에 그대로 적용하면 두 가지 문제가 있었습니다 — ① O(n²) 비용: 시퀀스 길이 n=96이면 attention 행렬이 96×96 = 9,216 entry. n이 커지면 비용이 제곱으로 증가. ② 한 timestep의 정보가 너무 작음: 단어와 달리 시계열의 한 점은 의미가 거의 없음. 주변 context가 있어야 의미.

IBM 연구팀의 통찰 — "한 timestep을 한 토큰으로 보지 말고, 12-16 timestep을 통째로 한 patch(=한 토큰)로 보자". 96 → 8 토큰으로 줄이면 attention 비용이 8² = 64로 144배 감소. 그러면서도 각 patch가 12 timestep의 의미를 통째로 담아 정보 손실은 거의 없습니다. ViT(Vision Transformer)가 이미지를 patch로 자른 것과 정확히 같은 발상.

추가 혁신 — Channel-Independent: 다변량 시계열의 각 변수(채널)를 독립적으로 학습. 변수 수에 robust해 신규 챔버 적응이 빠름.

Nie et al. (2023). "A Time Series is Worth 64 Words: Long-term Forecasting with Transformers", ICLR 2023. arXiv:2211.14730.

핵심 용어 4개

patch패치 (1 토큰)

연속된 12-16 timestep 묶음. 시계열의 "단어"에 해당. 한 patch = 한 token으로 Transformer 입력.

channel-independent변수 독립

다변량 시계열의 각 변수를 독립 채널로 학습. 변수 간 상관은 channel mixing으로 따로. 신규 변수 추가에 robust.

forecast horizon예측 시야

"앞으로 얼마나 예측할지" — 보통 24, 48, 96 step. 멀어질수록 신뢰구간이 넓어짐.

uncertainty band신뢰구간

예측값 ±2σ. 양산 적용 시 APC가 "이 예측을 얼마나 믿을지" 판단의 근거. Bayesian Last Layer 또는 Ensemble로 추정.

FOUNDATIONAL · 1989 · Watkins (Q-learning) · 2015 · Mnih (DQN)

강화학습 — Q-table을 시행착오로 학습한다

"어떻게 행동할까?"의 학습. 정답이 없는 환경에서 보상을 최대화하는 정책을 시행착오로 배웁니다. LG Display Mura 보정과 TSMC OHT 라우팅이 산업 적용 대표 사례.

WHY · 왜 만들어졌나

"정답이 없는 문제"를 풀어야 한다

지도학습(Supervised Learning)은 (입력, 정답) 쌍이 필요합니다. 그런데 게임이나 로봇 제어에서는 "이 상황에서 정답 행동"이 명확하지 않습니다 — 한 행동의 결과가 수십 step 후에야 보상으로 나타날 수 있기 때문 (체스에서 30수 후 승리).

1989년 Watkins의 박사논문이 이 문제를 풀었습니다. "각 (상태 s, 행동 a) 쌍에 대해 미래 누적 보상의 기댓값 Q(s,a)를 학습" → 학습된 Q-table에서 argmax를 취하면 최적 정책. Bellman 방정식이 핵심:
Q(s,a) = r + γ · max Q(s', a')

2015년 DeepMind의 DQN(Deep Q-Network) 논문은 Q-table을 신경망으로 대체해 Atari 게임을 사람 수준으로 해결, RL 시대를 본격 열었습니다. 이후 PPO, SAC, CQL 등이 등장했고, 양산 라인은 Offline RL (CQL)이 안전한 적용 경로로 자리잡았습니다.

Watkins (1989). "Learning from Delayed Rewards", PhD thesis. / Mnih et al. (2015). "Human-level control through deep reinforcement learning", Nature 518, 529-533.

핵심 용어 4개

Q(s,a)행동 가치

"상태 s에서 행동 a를 했을 때 미래 누적 보상의 기댓값". 학습 결과물. 최적 정책 = 각 s에서 argmax_a Q(s,a).

α (alpha)학습률

새 경험을 얼마나 반영할지. 0.1~0.5. 너무 크면 불안정, 너무 작으면 학습이 느림. Q ← Q + α·(target − Q)

γ (gamma)할인 인자

미래 보상을 얼마나 중요시할지. 0.9~0.99. 1에 가까우면 장기 계획, 0에 가까우면 즉시 보상만.

ε (epsilon)탐험률

ε 확률로 무작위 행동 (탐험), 1-ε 확률로 현재 최선 행동 (활용). 학습 초반엔 크게(0.3~1.0), 후반엔 작게(0.01).

Q-learning 한 step의 갱신 공식 target = r + γ · max_a' Q(s', a') ← 받은 보상 + 미래 최선 가치 Q(s,a) ← Q(s,a) + α · (target − Q(s,a)) ← 차이만큼 업데이트 핵심: 다음 상태 s'의 최선 가치를 부트스트랩 → 한 step 정보가 점차 멀리 전파
SIMULATION · 데모 사용법
  1. 5×6 grid에서 노란 점(agent)이 S(시작)에서 ★(목표, +1)에 도달하는 정책을 학습합니다. ✖(함정, −1)과 ▣(벽)을 피해야 합니다.
  2. 1 step으로 한 행동씩 수동 진행, 1 episode로 한 판 자동, Auto-train 50 ep으로 학습 가속.
  3. 각 셀의 4 삼각형이 4 방향(↑→↓←) Q-값을 색으로 표시. 파랑=양수(좋음), 빨강=음수(나쁨), 회색=0.
  4. 학습이 진행되면 굵은 화살표(현재 정책 = argmax_a Q)가 목표를 향해 자연스럽게 형성됩니다.
  5. α / γ / ε 슬라이더로 학습률·할인·탐험을 조절해 보세요. ε를 0으로 줄이면 학습된 정책만 사용 (탐험 없음).

FOUNDATIONAL · 1978 · Mockus · 2016 review · Shahriari et al.

Bayesian Optimization — "다음 실험을 똑똑하게 선택"

실험 한 번이 비싸고 느릴 때 (recipe 튜닝, 신규 도입 등) — "몇 번 해본 결과로 미지 함수를 추정하고, 가장 정보 가치 높은 다음 점을 고르는" 알고리즘. DoE를 30-50% 압축해 양산 RL 진입의 안전한 첫 단계.

WHY · 왜 만들어졌나

실험 한 번이 비싸고 느릴 때, 격자 탐색은 비현실적

새 recipe를 5개 변수로 튜닝한다고 해봅시다. 각 변수에 10개 후보가 있으면 격자 탐색은 10⁵ = 10만 실험. 한 실험에 1일 걸리면 274년. 현실적으로 불가능합니다.

1978년 Mockus의 통찰 — "미지의 함수에 대한 확률적 모델(Gaussian Process)을 만들고, 그 모델을 가지고 '다음에 어디서 실험할지'를 정보 이론적으로 결정하자". GP는 본 점들 사이를 부드럽게 잇고 "본 적 없는 곳일수록 불확실성이 크다"는 정보를 함께 제공. 이 평균(μ)과 표준편차(σ)를 결합한 acquisition function이 다음 실험 위치를 제안합니다.

결과 — 같은 정확도를 위해 격자 탐색 1000번이 필요하던 것이 BO로는 30-100번이면 충분. 30-50배 가속. 2016년 Shahriari의 IEEE 리뷰 논문이 fab 산업 적용을 본격 가속했습니다.

Mockus (1978). "On Bayesian methods for seeking the extremum". / Shahriari et al. (2016). "Taking the Human Out of the Loop", Proc. IEEE 104(1).

핵심 용어 4개

GP (Gaussian Process)가우시안 과정

"미지의 함수가 어떻게 생겼을지"의 확률 분포. 본 점들 사이를 부드럽게 잇고, 본 적 없는 곳일수록 불확실성이 큼.

μ(x) / σ(x)평균 / 표준편차

GP가 점 x에서 추정하는 평균과 불확실성. μ는 최선 예측, σ는 모름의 정도. 둘 다 같이 본다.

acquisition function획득 함수

"다음에 어디서 실험할지"를 결정. 대표적으로 UCB μ + 2σ (좋아 보이는 + 모르는 곳), EI (Expected Improvement).

exploit / explore활용 / 탐험

μ만 보면 활용 (보장된 좋은 곳), σ만 보면 탐험 (모르는 곳). UCB·EI는 둘의 균형.

UCB acquisition (가장 단순한 형태) acq(x) = μ(x) + κ · σ(x) ← κ = 2 (95% upper confidence) 다음 샘플 위치: x_next = argmax_x acq(x) 직관: "예측 평균이 좋고 OR 모름이 큰 곳" 둘 다 가치
SIMULATION · 데모 사용법
  1. 1차원 미지 함수 (점선, 회색)가 숨겨져 있고, 초기 2개 샘플(빨간 점)로 시작합니다.
  2. 상단 그래프 — GP 평균 μ(파란선) + ±2σ 신뢰구간(파란 띠). 본 점에서는 σ가 0에 가깝고, 멀어지면 σ가 커짐.
  3. 하단 그래프 — acquisition function. argmax 위치에 빨간 점선이 표시됨 (다음 샘플 위치).
  4. 다음 샘플을 누르면 그 위치에서 실험을 실행 (실제 함수 값 + 노이즈)하고 GP가 갱신됩니다.
  5. Acquisition 변경으로 UCB / EI / 순수 탐험(σ만) / 순수 활용(μ만) 비교. 처음엔 탐험 많이, 나중엔 활용 많이 해야 효율적.
  6. 5-10 샘플 안에 함수의 최댓값 근처에 도달하는 것을 확인 — 이게 BO의 위력.
BO 시뮬레이션 — GP posterior + acquisition로 다음 실험 위치 결정
Acquisition
목적함수
"다음 샘플"로 BO 사이클 시작.
상단=실제 함수(점선)+GP μ(파란선)+±2σ 띠. 하단=acquisition. 빨간 점선=다음 샘플 위치.

  • Bosch Reutlingen — 다품종 소량 환경에서 신제품 라인 가동 시 BO로 빠른 ramp.

FOUNDATIONAL · 2020 · Ho, Jain, Abbeel (UC Berkeley) — DDPM

Diffusion — "노이즈 → 이미지"의 단계적 복원

Stable Diffusion · DALL-E · Midjourney의 기반 기술. fab에서는 long-tail 결함 합성(Mura·particle)과 EUV stochastic 모델링에 사용. Intel GFA, ASML EUV, Samsung Generative Defect Synthesis가 대표 사례.

WHY · 왜 만들어졌나

2020년 이전: 이미지 생성 모델은 GAN의 학습 불안정으로 골치였다

2014년 GAN(Goodfellow)이 처음으로 사실적 이미지 생성을 가능하게 했지만, 두 가지 문제가 끈질겼습니다 — ① 학습 불안정: generator와 discriminator의 최소-최대 게임이 자주 발산 또는 mode collapse. ② 모드 다양성 부족: 일부 패턴만 생성하는 경향.

2020년 UC Berkeley의 Ho, Jain, Abbeel이 발표한 DDPMDenoising Diffusion Probabilistic Models은 완전히 다른 접근을 제시했습니다 — "깨끗한 이미지에 점진적으로 노이즈를 추가하는 forward process를 정의 → 역과정을 신경망이 학습하면 노이즈에서 이미지를 만들 수 있다".

이 단순한 아이디어가 학습 안정성을 극적으로 개선했고, 2022년 Stable Diffusion (Latent Diffusion)으로 발전해 오늘날 이미지 생성 분야를 사실상 독점합니다. fab에서는 결함 데이터 부족 (long-tail) 문제를 풀기 위해 정상 이미지로부터 결함 합성에 널리 사용됩니다.

Ho, Jain, Abbeel (2020). "Denoising Diffusion Probabilistic Models", NeurIPS 2020. arXiv:2006.11239.

핵심 용어 4개

forward process (q)전방 확산

깨끗한 x₀에 단계적으로 가우시안 노이즈를 추가. T=1000 step 후 x_T ≈ N(0,I) (완전 노이즈). 학습용 데이터 생성에 사용.

reverse process (p)역 디노이징

노이즈에서 이미지로 거꾸로 — 신경망 ε_θ가 "현재 상태에서 추가된 노이즈"를 예측해 빼는 것을 반복.

α̅_t (alpha bar)누적 보존 비율

"timestep t에서 원본이 얼마나 남았는가"의 척도. t=0이면 1(원본), t=T면 0(완전 노이즈). cosine schedule이 표준.

ε_θ (epsilon theta)노이즈 예측 신경망

학습 대상. "x_t에 대해 어떤 노이즈가 추가됐는지"를 예측. 이 예측을 빼면 한 step 디노이징 완료.

DDPM 학습 목표 — 매우 단순 Forward: x_t = √α̅_t · x_0 + √(1−α̅_t) · ε ← ε ~ N(0,I) 무작위 노이즈 Loss: L = ‖ε − ε_θ(x_t, t)‖² ← 추가된 노이즈를 맞추기 Generation (reverse): x_T (noise) → ... → x_0 (image) ← step-by-step 디노이징
SIMULATION · 데모 사용법
  1. 왼쪽 = forward (학습용). 오른쪽 = reverse (생성용). 두 흐름이 거울상으로 동시에 보입니다.
  2. 대상 선택: 원 / 십자(FMM 정렬) / Mura 패턴 / S 글자 — 학습 시 깨끗한 원본으로 사용할 이미지.
  3. 슬라이더 t를 0 → 100으로 움직이며 forward 과정을 단계적으로 보세요. t가 커질수록 점점 노이즈로.
  4. 오른쪽 reverse는 같은 t에서 반대 방향 — t가 커질수록 reverse 시점에서 x_{T-t}는 더 깨끗해짐.
  5. 하단 α̅_t 값과 timestep 진행 막대로 cosine schedule이 어떻게 작동하는지 확인.
  6. 자동 재생으로 t=0 → 100 → 0 사이클이 자동 반복.

  • Samsung Memory Generative Defect Synthesis — wafer map long-tail 패턴을 GAN/Diffusion으로 합성 (GTC 2024 demo).
  • ControlNet + Defect Mask — 정상 panel + 결함 위치 mask → 결함 panel 합성. fab 내부 도구로 다수 활용.
