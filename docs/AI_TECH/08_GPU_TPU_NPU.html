GPU · TPU · NPU 근본 차이 — 같은 신경망, 다른 하드웨어

세 칩 모두 행렬 곱셈을 빠르게 처리하지만, 설계 철학이 다릅니다. GPU는 "범용 병렬 처리기", TPU는 "행렬 곱셈 전용 ASIC", NPU는 "엣지 추론 가속기". 각각의 강점과 약점을 정확히 이해해야 어디에 무엇을 써야 할지 보입니다.

WHY · 왜 3종류나 필요한가

같은 신경망이라도 "학습 vs 추론 vs 엣지"의 요구가 정반대

GPT-4 같은 거대 모델 하나가 실제로 사용되는 흐름을 보면 — ① 학습 단계: 1만 GPU 클러스터에서 수개월. ② 클라우드 추론: 수만 명이 동시에 사용. ③ 엣지 추론: 휴대폰에서 1명이 사용. 각 단계의 최적 칩이 다릅니다.

학습은 거대한 메모리·전력·연결성이 필요하니 GPU 또는 TPU. 클라우드 대량 추론은 처리량/달러 효율이 중요하니 TPU/특수 ASIC. 엣지 추론은 전력 절약과 즉시성이 핵심이니 NPU. 같은 칩 하나로 다 못 합니다 — 각각의 영역에 최적화된 별도 칩이 필요합니다.

1.1 세 칩의 설계 철학 한눈에

🟢 GPU — Graphics Processing Unit

"범용 병렬 처리기"

원래 그래픽 픽셀 처리용. 행렬 곱셈에 자연스럽게 맞아 AI에 채택됨. 유연성 + 성능의 균형.

  • 코어: 16,896 CUDA + 528 Tensor Core (H100)
  • 강점: 어떤 모델도 돌아감, 활발한 SW 생태계 (CUDA, PyTorch)
  • 약점: 그래픽 잔재 회로로 다소 비효율, 전력 많이 소모
  • 대표 제품: NVIDIA H100/H200 · Blackwell B200 · GB200
  • 가격: H100 1대 ≈ $30,000~40,000
  • 전력: 700W (H100) ~ 1,000W (B200)
🔵 TPU — Tensor Processing Unit

"행렬 곱셈 전용 ASIC"

Google이 2015년부터 자체 개발. 오직 신경망만 위해 설계된 칩. 그래픽 회로 없음. 행렬 곱셈에 100% 최적화.

  • 코어: Systolic Array (수천 곱셈기 격자)
  • 강점: 같은 와트당 GPU 대비 2-3배 전력 효율, Pod 단위 초고속 인터커넥트
  • 약점: Google 클라우드에서만 사용 가능 (외부 판매 X), TensorFlow/JAX 친화
  • 대표 제품: TPU v5p (2024) · Trillium v6 (2024)
  • 가격: 클라우드 대여 ≈ $4-8/시간 (v5p)
  • 전력: ~450W (v5p)
🔴 NPU — Neural Processing Unit

"엣지/모바일 AI 가속기"

스마트폰·로봇·차량 같은 엣지 디바이스에 탑재되는 작은 ASIC. 추론 전용. 전력 최적화가 1순위.

  • 코어: 작은 행렬 가속기 + 양자화 회로
  • 강점: 초저전력 (<10W), 초저지연 (즉시 응답), 인터넷 불필요
  • 약점: 학습 못 함, 큰 모델 못 돌림, 정밀도 제한 (INT8/FP8)
  • 대표 제품: Apple Neural Engine (M4: 38 TOPS) · Qualcomm Hexagon · Tesla FSD chip
  • 가격: 호스트 디바이스에 통합 (별도 가격 X)
  • 전력: 1-15W

2

학습 vs 추론 vs 엣지 — 어디에 어떤 칩을 쓰나

AI 시스템의 생명주기는 크게 3단계 — 학습 → 클라우드 추론 → 엣지 추론. 각 단계는 완전히 다른 요구를 가지고, 그래서 다른 칩이 최적입니다.

① 학습 (Training)

모델 만들기 — 1회성 거대 작업

요구: 거대 메모리, 초고속 인터커넥트, 며칠~수개월 연속 운영

적합 칩: GPU H100/B200 클러스터 또는 TPU v5p Pod

  • GPT-4 학습 ≈ 25,000 NVIDIA A100 × 90일
  • Gemini Ultra ≈ TPU v5p × 수만 개
  • Llama 3 405B ≈ 16,000 NVIDIA H100
  • 비용: $50M ~ $200M / 모델 1회
② 클라우드 추론 (Cloud Inference)

학습된 모델로 수천만 요청 처리

요구: 처리량/달러 효율, 대용량 메모리, 24/7 안정성

적합 칩: GPU H100/L40S, TPU v5e, AWS Trainium, 전용 ASIC

  • ChatGPT 서비스: 수만 GPU + KV cache 최적화
  • Google Search AI: TPU v5e (학습보다 추론 효율 높은 변형)
  • Meta Llama API: NVIDIA H100
  • 처리량 ≈ 토큰당 $0.001 ~ $0.03
③ 엣지 추론 (Edge Inference)

휴대폰·로봇·차량 안에서 실시간 추론

요구: 초저전력, 즉시 응답, 인터넷 불필요, 프라이버시

적합 칩: NPU (Apple Neural Engine, Snapdragon NPU, Tesla FSD chip, Jetson Orin)

  • iPhone Siri/Apple Intelligence: M4 Neural Engine
  • Galaxy Bixby: Qualcomm Hexagon NPU
  • Tesla 자율주행: 자체 FSD chip
  • 로봇 제어: NVIDIA Jetson Orin

2.1 같은 모델의 3가지 다른 운명

예시 — Llama 3 70B 한 모델의 일생

학습 → 클라우드 → 엣지에서 각각 어떤 칩이 쓰이나

[학습 단계 — 1회만] 하드웨어: NVIDIA H100 16,000대 (Meta 자체 클러스터) 시간: 약 30일 연속 비용: 컴퓨트만 ~$30M (전기료 포함) 결과물: 가중치 70B개 = 약 140GB (FP16) ↓ 학습 완료, 가중치 공개 [클라우드 추론 — 매일 수억 요청] 하드웨어: NVIDIA H100 1대 (또는 4대 분산) 처리량: 초당 ~50 토큰/스트림 × 수십 동시 비용: API 호출당 ~$0.01-0.05/1K tokens 메모리: 70B × 2 bytes = 140GB (FP16) → H100 80GB에 안 맞음 → 분산 필요 또는 INT8 양자화로 70GB → H100 1대로 가능 ↓ 모델 압축 (양자화 + distillation) [엣지 추론 — iPhone/로봇 안에서] 모델: Llama 3.2 1B (70B → 1B로 distill, 70배 작아짐) 하드웨어: Apple M4 Neural Engine (38 TOPS) 메모리: 1B × INT4 = 0.5GB (휴대폰에 들어감) 처리량: 초당 ~25 토큰 (즉시 응답) 비용: $0 (디바이스 비용에 포함) 한계: 모델 작아 정확도 ↓, 복잡 추론 X
핵심 — 같은 모델 패밀리(Llama 3) 안에서도 학습용 70B는 H100 클러스터에서, 클라우드 추론은 H100 1대에서, 엣지 추론은 1B로 압축돼 NPU에서 — 3가지 칩이 모두 동원됩니다. 어느 한 칩으로 다 못 합니다.

2.2 의사결정 프레임 — "어떤 칩을 쓸까?"

3

LLM 케이스 deep dive — GPT · Gemini · Claude · 온디바이스

LLM은 AI 하드웨어의 가장 큰 수요처이자 가장 명확한 사례입니다. 학습/추론/엣지에 어떤 칩이 어떻게 쓰이는지 실제 사례로 추적합니다.

WHY · LLM이 하드웨어 산업을 흔들다

NVIDIA 시가총액 $4조 — 거의 LLM 덕분

GPT-4 (2023), Claude 3 (2024), Gemini Ultra (2024) — 거대 LLM 학습은 한 번에 $50M~200M의 컴퓨트 비용이 듭니다. 1만 GPU 클러스터를 수십 일 운영하는 비용입니다.

추론도 만만치 않습니다. ChatGPT가 매일 1억 명 사용하면 추론 비용만 일년에 수십억 달러. 그래서 OpenAI · Google · Meta · Anthropic 모두 자체 학습 인프라 + 효율적 추론 인프라 + 엣지 모델을 동시에 운영합니다. 이게 GPU(NVIDIA), TPU(Google), 자체 ASIC, NPU(Apple/Qualcomm) 시장이 모두 폭발적으로 성장하는 이유입니다.

3.1 학습 — 거대 GPU/TPU 클러스터

OpenAI GPT-4 / GPT-5 학습

CLOUD TRAINING · NVIDIA GPU CLUSTER

OpenAI는 Microsoft Azure 클라우드의 거대 GPU 슈퍼컴퓨터를 사용. GPT-4는 약 25,000 NVIDIA A100 GPU로 90-100일에 걸쳐 학습된 것으로 추정. GPT-5는 H100/H200 기반 약 50,000 GPU 클러스터로 알려짐.

핵심 선택 이유: NVLinkNVIDIA가 GPU끼리 직접 연결하는 고속 인터커넥트. 일반 PCIe보다 5~10배 빠름. 다중 GPU 학습의 표준와 InfiniBand데이터센터에서 서버 간 초고속 통신용 네트워크 표준. 일반 이더넷보다 지연시간 1/10 이하 인터커넥트로 GPU 간 통신이 빠름. CUDA 생태계로 PyTorch가 잘 돌아감. 모델 병렬화·파이프라인 병렬화의 표준.

핵심 선택 이유: AWS의 거대 인프라 활용 + 비용 효율. Trainium 2는 행렬 곱셈 전용 ASIC으로, AWS는 동급 GPU 대비 가격-성능비 30~40% 향상을 표방.

3.2 클라우드 추론 — 효율과 처리량

ChatGPT 서비스 추론

CLOUD INFERENCE · NVIDIA H100 + 양자화

매일 약 1억 명이 사용. 거대 모델(GPT-4o, o3)을 양자화(FP8)와 KV cacheKey-Value 캐시 — Transformer가 이전에 처리한 토큰의 중간 결과(K·V 행렬)를 저장해 다음 토큰 생성 시 재사용. 추론 속도 결정적 요소 최적화로 H100 클러스터에서 서비스. 한 요청당 처리량을 최대화하기 위해 vLLMUC Berkeley가 만든 오픈소스 LLM 추론 엔진. PagedAttention 기법으로 메모리 효율 최대화, TensorRT-LLMNVIDIA의 LLM 추론 가속 라이브러리. CUDA 최적화로 H100/B200 활용 극대화 같은 추론 엔진 활용.

핵심 비용: 사용자 1명이 토큰 1000개 받는 데 ~$0.01. 매일 수억 토큰 → 연간 추론 비용 수십억 $.

Google Search AI Overview · Gemini Flash

CLOUD INFERENCE · TPU V5E

Google 검색의 AI Overview는 매일 수십억 회 호출. 학습용 TPU v5p보다 추론에 최적화된 TPU v5e(efficiency)를 사용. 가격은 v5p의 절반, 성능은 70% 수준이지만 추론 처리량/달러는 더 좋음.

Physical AI · 로봇 — VLA 모델과 탑재 하드웨어

Figure 02, 1X NEO, Tesla Optimus 같은 휴머노이드 로봇이 2024-2026년 폭발적으로 등장. 어떤 모델이 어떤 칩에서 돌고 있는지 실제 사례로 추적합니다.

WHY · "Physical AI"의 시대

2024년부터 LLM의 다음 단계 = 물리 세계와 상호작용하는 AI

NVIDIA Jensen Huang의 2024 발언 — "이번 산업혁명은 Physical AI가 주인공". LLM이 텍스트 세계를 정복했다면, 이제는 카메라로 보고·말로 듣고·로봇 팔로 행동하는 AI가 다음 단계입니다.

핵심 모델은 VLAVision-Language-Action, 비전-언어-행동 모델: 이미지/비디오 + 자연어 명령 → 로봇 행동(joint torques)을 생성. Google RT-2 (2023), Physical Intelligence π0 (2024), Figure Helix (2025) 등이 대표. 이 모델들은 학습은 클라우드 GPU, 실행은 로봇 안 NPU/Jetson이라는 이중 구조로 운영됩니다.

4.1 VLA 모델 — 로봇이 보고·듣고·행동하는 메커니즘

VLA 모델의 4단계 추론

Figure 02 로봇이 "냉장고에서 사과 가져와"라는 명령을 처리하는 흐름

[입력] 비전: 카메라 6개 (전후좌우상하), 각 30 fps × 1280×720 RGB 언어: "냉장고에서 사과 가져와" (음성 → 텍스트) 상태: 로봇 관절 28개 현재 각도 [VLA 모델 처리 — 보통 1B-7B 파라미터] Step 1: 비전 인코더 (CLIP/DINOv2) → 이미지 임베딩 Step 2: 언어 인코더 (LLM) → 명령 임베딩 Step 3: 통합 Transformer → 행동 시퀀스 디코딩 Step 4: 매 초 50-100회 갱신 (50-100 Hz) [출력] 행동: 28개 관절의 다음 0.01초 동안의 토크/속도 명령 계획: "1. 몸 회전 → 2. 팔 뻗기 → 3. 손가락 잡기 → 4. 들어올리기" [제어 빈도] 로봇 제어 명령은 초당 100-1000회 갱신해야 함 → 추론 지연 < 10ms 필수 → 클라우드 추론 불가능, 로봇 안 NPU/Jetson 필수

자율차 — Tesla FSD · NVIDIA Drive Thor · Mobileye

WHY · 자율차 칩의 특수성

"실시간 안전 + 자동차 비용"이라는 이중 제약

자율차의 칩은 일반 AI 칩과 다른 두 가지 제약을 받습니다 — ① 자동차 등급 안전 (ASIL-D): 1초 동안 멈추면 사고. 이중·삼중 안전 회로 필수. ② 자동차 가격 압박: 칩 1대당 $1000 이상이면 차 가격에 부담. 그래서 H100 같은 거대 GPU($30K)는 못 씀.

5.6 학습은 어디서? — 모든 자율차 회사가 GPU 클러스터에서 학습

INDUSTRY · 학습 인프라 비교

차량용 NPU는 작아도, 학습은 거대 GPU 클러스터

  • Tesla Dojo + 35K H100 — 100만 마일/일 영상 학습. 매주 모델 갱신.
  • Waymo — Google TPU + 시뮬레이션 100억 마일.
  • Mercedes (Drive Pilot) — NVIDIA DGX 클러스터.
  • Mobileye — Intel Habana + 자체 클러스터.
  • 중국 (NIO · XPeng · 화웨이) — Huawei Ascend + NVIDIA hybrid.

핵심 패턴 — 모든 회사가 "클라우드 학습 + 차량 추론"의 이중 구조. 차에 들어가는 칩은 작고 효율적인 NPU/ASIC, 학습 클러스터는 거대 GPU. 이 분리 덕분에 차량 가격 부담을 줄이면서도 거대 모델 학습 가능.

🔴 NPU의 영역
"엣지 추론" 전담. 학습 못 함, 큰 모델 못 돌림.

마지막 핵심 — "GPU vs TPU vs NPU"는 경쟁이 아니라 분업입니다. 같은 모델 하나(예: Llama 3 또는 자율차 신경망)도 학습/클라우드/엣지에 따라 3가지 칩이 모두 동원됩니다. "어느 칩이 더 좋은가"가 아니라 "내 작업이 어디에 속하는가"가 올바른 질문. 그리고 모든 단계에서 NVIDIA의 SW 생태계(CUDA·PyTorch·TensorRT)가 흐름을 지배 — 이게 NVIDIA $4조 시가총액의 진짜 비밀입니다.
