CNNConvolutional Neural Network, 합성곱 신경망 패밀리 — 결함 분류·검사의 표준

ResNet → ConvNeXt → DINOv2 → SAM 2
원본 — Origin
ResNet (Residual Network) · He, Zhang, Ren, Sun · Microsoft Research · 2015
핵심 아이디어: skip connection y = F(x) + x으로 152층 깊이의 학습을 가능하게 함. ImageNet top-5 오차를 3.57%로 낮춰 사람 수준을 처음 넘긴 모델.
He et al., "Deep Residual Learning for Image Recognition", CVPR 2016. arXiv:1512.03385
주요 진화 (Evolution)
2017 · ResNeXt
Cardinality 도입 — 같은 깊이로 더 강한 표현
Facebook AI · group convolution을 ResNet에 결합. 같은 파라미터 수로 정확도 향상.
2019 · EfficientNet
Depth · Width · Resolution 동시 스케일링
Google Brain · compound scaling 법칙 제안. 모바일 배포의 표준이 됨.
2022 · ConvNeXt
ViT 시대에 CNN이 다시 살아남다
Meta · Depthwise conv + LayerNorm + GELU + Inverted bottleneck — ViT의 디자인 요소를 CNN에 역수입. ImageNet에서 Swin-T 추월.
2023 · ConvNeXt V2
Masked AutoEncoder 사전학습 통합
Meta · MAE 자기지도학습으로 라벨 없는 사전학습. 산업 검사 SOTA.
2023 · DINOv2
142M 자연이미지 SSL — "라벨 0장 백본"
Meta · Knowledge distillation 기반 self-supervised. linear probe만으로도 95%+ 정확도. 결함 검사 분야의 즉시 활용 가능 백본.
2024 · SAM 2 (Segment Anything Model)
Promptable segmentation의 비디오 확장
Meta · 51K 비디오 + 643K segment 학습. zero-shot으로 결함 영역만 잘라내기 가능.
팹 적용 변형 — Applied Modification
  • Domain-Specific Fine-Tuning: ImageNet 사전학습 ResNet/ConvNeXt를 고객 fab의 SEMScanning Electron Microscope, 주사 전자 현미경·AOIAutomated Optical Inspection, 자동 광학 검사 이미지로 last-layer만 fine-tune (Intel 2018-2024 사례)
  • Multi-Perspective Input: 단일 RGB 채널 대신 회절·편광·각도 다채널을 동시 입력 (KLA 2023~)
  • DINOv2 임베딩 + Memory Bank: ImageNet 학습 백본을 동결하고 정상 이미지 임베딩을 저장 후 거리 비교 (PatchCore 패턴, Applied Materials 2023~)
  • Active Learning Loop: 모델 불확실성이 높은 이미지를 우선 라벨링 → 재학습 (Applied Materials ExtractAI)
  • SAM 2 + Domain CNN Hybrid: SAM 2로 결함 영역 분할 → 도메인 특화 CNN으로 분류 (2024~ 다수 fab)

Transformer 패밀리 — 모든 토큰이 모든 토큰을 보다

Attention → BERT → GPT → ViT → Swin → MoE
원본 — Origin
Transformer ("Attention is All You Need") · Vaswani et al. · Google Brain · 2017
핵심 아이디어: 순환구조(RNNRecurrent Neural Network, 순환 신경망)를 버리고 self-attention으로 모든 위치 간 관계를 직접 학습. Attention(Q,K,V) = softmax(QKᵀ/√d) · V. 병렬화 가능.
Vaswani et al., "Attention is All You Need", NeurIPS 2017. arXiv:1706.03762
주요 진화 (Evolution)
2018 · BERT
양방향 사전학습
Google · masked language modeling. NLP 성능 도약.
2018-2020 · GPT-1/2/3
Decoder-only 거대 LM
OpenAI · 175B 파라미터까지 확장. zero-shot 성능 발견.
2020 · ViT (Vision Transformer)
이미지를 16×16 patch로 토큰화
Google · 비전에 Transformer 직접 적용. JFT-300M 사전학습으로 CNN 추월.
2021 · Swin Transformer
Shifted Window Attention
Microsoft · 계층 구조 + 지역 윈도우. 일반 ViT보다 데이터 효율적.
2022 · Flash Attention
메모리 IO 최적화
Stanford · attention의 GPU 메모리 접근을 재구성 → 학습 2배 가속.
2024 · Mamba / SSM
O(n²) → O(n) 도전
CMU · State Space Model로 attention 대체. 긴 시퀀스에 강점.
팹 적용 변형 — Applied Modification
  • Patch + Channel Independent: 시계열에서 각 변수를 독립 채널로 patch화 (PatchTST 패턴, SK hynix Panoptes)
  • Cross-Tool Attention: 같은 챔버 모델 여러 대 간 공통 trunk + tool-specific head 구조 (Gauss Labs Panoptes 2024 SPIE)
  • Heterogeneous Graph Transformer (HGT): chamber/tool/recipe/lot 노드 타입별로 attention parameter 분리 (TSMC IEDM 2022~)
③

시계열 패밀리 — VMVirtual Metrology, 가상 계측의 심장

LSTM → Informer → PatchTST → iTransformer → TimesFM
원본 — Origin
LSTMLong Short-Term Memory, 장단기 기억 신경망 · Hochreiter, Schmidhuber · Technical University Munich · 1997
핵심 아이디어: forget · input · output 3개 게이트로 장기 의존성을 학습. RNN의 vanishing gradient 문제를 해결. 2010년대 시계열의 표준.
Hochreiter & Schmidhuber, "Long Short-Term Memory", Neural Computation 1997.
주요 진화 (Evolution)
2017 · Transformer 시계열 적용
Attention의 시계열 도입
긴 시퀀스에서 O(n²) 부담으로 직접 적용은 한계.
2021 · Informer
ProbSparse Self-Attention
AAAI Best Paper · sparse attention으로 O(n log n). 장기 예측 향상.
2021 · Autoformer
Decomposition + Auto-Correlation
trend / seasonal 분해 후 attention 적용.
2023 · PatchTST
시계열을 patch로 자르기
IBM · 단순한데 강함. 시퀀스 96 → patch 8로 attention 비용 144× 감소. 양산 배포 1순위.
2024 · iTransformer
변수 차원에 attention 적용
Tsinghua · 시간축이 아닌 변수 간 관계에 attention. 다변량 강함.
2024 · TimesFM (Google)
시계열 Foundation Model
100B time-points 사전학습 · zero-shot forecast 가능. 200M 파라미터 decoder-only.
2024 · Chronos (Amazon) · Moirai (Salesforce) · Lag-Llama
오픈 시계열 FM 동시 등장
HuggingFace 공개 · 도메인 데이터 없이 빠른 PoCProof of Concept, 개념 증명 가능.
팹 적용 변형 — Applied Modification
  • Bayesian Last Layer (BLL): PatchTST/iTransformer 마지막 layer만 베이지안화 → 예측 + 불확실성 동시 출력. APCAdvanced Process Control, 고도 공정 제어가 "모름"을 받아들일 수 있게 (Gauss Labs Panoptes)
  • Heteroscedastic Loss: 평균 μ와 분산 σ를 동시 예측하는 NLL loss. 잘 보정된 uncertainty를 위해 (SPIE AL 2024)
  • PM-Aware Sequence Token: 예방정비(PM) 이벤트를 sequence에 special token으로 주입. PM 전후 분포 변화를 명시적으로 학습
  • EWC (Elastic Weight Consolidation) Online Update: 신규 측정치가 들어올 때마다 last-layer만 점진 업데이트. 전체 재학습 없이 drift 추적
  • Tool-to-Tool Domain Adaptation: 공통 trunk + chamber-specific head로 챔버 간 변동 흡수

Tabular 패밀리 — 수율 예측·RCA의 왕도

XGBoost → LightGBM → CatBoost → SHAP → TabPFN
원본 — Origin
XGBoost (eXtreme Gradient Boosting) · Tianqi Chen, Carlos Guestrin · University of Washington · 2016
핵심 아이디어: gradient boosting trees를 정규화·병렬화·sparsity-aware로 산업 수준 구현. Kaggle 대회 압도. 표 형태 데이터의 사실상 표준.
Chen & Guestrin, "XGBoost: A Scalable Tree Boosting System", KDD 2016.
주요 진화 (Evolution)
2017 · LightGBM
Histogram + leaf-wise growth
Microsoft · histogram 기반 분기 + leaf-wise. 학습 속도 5-10배.
2017 · SHAP
Shapley value 기반 예측 분해
Lundberg, Lee · 게임이론으로 feature 기여도를 수학적으로 유일 분해. RCARoot Cause Analysis, 근본 원인 분석의 표준.
2018 · CatBoost
Categorical 자동 처리
Yandex · ordered boosting + target encoding 자동.
2023 · TabPFN
Transformer 기반 zero-shot tabular
Hollmann et al. · 합성 tabular 데이터로 사전학습된 Transformer가 신규 데이터셋을 zero-shot으로 분류. 1만 행 미만에서 XGBoost 추월.
팹 적용 변형 — Applied Modification
  • Lot-Level Aggregation Features: chamber별 통과 lot의 mean/std/max/min을 wide feature로 변환 (Intel · TSMC 표준)
  • SHAP-Driven RCA Pipeline: SHAP 값이 일관되게 음의 기여를 보이는 chamber/recipe 조합을 자동으로 alert (Samsung · SK hynix 사용)
  • Gain × Cover 기반 Pareto: feature importance를 SHAP뿐 아니라 gain·cover로 cross-check (KLA Klarity 2023)

GNNGraph Neural Network, 그래프 신경망 패밀리 — chamber-tool-lot 그래프 학습

GCN → GraphSAGE → GAT → HGT
원본 — Origin
GCN (Graph Convolutional Network) · Thomas Kipf, Max Welling · University of Amsterdam · 2017
핵심 아이디어: 인접 행렬을 정규화한 후 layer마다 H' = σ(Â · H · W). 노드가 이웃의 평균을 받아 자신을 갱신.
Kipf & Welling, "Semi-Supervised Classification with Graph Convolutional Networks", ICLR 2017.
주요 진화 (Evolution)
2017 · GraphSAGE
Sampling 기반 inductive learning
Stanford · 이웃 sampling으로 대규모 그래프 학습. Pinterest 등 산업 첫 도입.
2018 · GAT
Attention으로 이웃 가중치 학습
DeepMind · 모든 이웃을 동등 평균하지 않고 attention으로 차등.
2020 · HGT (Heterogeneous Graph Transformer)
노드/엣지 타입별 파라미터 분리
UCLA · chamber/tool/recipe/lot 같은 이질적 노드 타입을 각각 별도 attention head로 학습.
2024 · Graph Transformer Variants
Positional encoding + edge feature
시간 정보 (lot이 통과한 순서)를 positional encoding으로 주입.
팹 적용 변형 — Applied Modification
  • Time-Aware HGT: lot이 통과한 시간 순서를 edge timestamp로 추가. "어떤 chamber에서 언제" 처리됐는지 명시 (TSMC IEDM 2022)
  • Multi-Type Edge: 같은 chamber 안에서도 recipe step별 edge type 분리
  • Yield Label as Node Attribute: lot의 final yield를 supervised target으로 두고 message passing

RLReinforcement Learning, 강화학습 패밀리 — APC의 미래

DQN → PPO → SAC → CQL/IQL → Decision Transformer → DreamerV3
원본 — Origin
DQN (Deep Q-Network) · Mnih et al. · DeepMind · 2015 (Nature)
핵심 아이디어: Q-learning의 Q-table을 신경망으로 표현 + replay buffer + target network. Atari 49개 게임에서 사람 수준 성능. 딥러닝 RL의 시작.
Mnih et al., "Human-level control through deep reinforcement learning", Nature 518, 2015.
주요 진화 (Evolution)
2017 · PPO
Proximal Policy Optimization
OpenAI · clipped objective로 안정적 policy gradient. ChatGPT RLHF에도 사용.
2018 · SAC
Soft Actor-Critic
UC Berkeley · entropy 정규화 + off-policy. 연속 행동 제어에 강함.
2020 · CQL · IQL
Offline RL — 로그만으로 학습
UC Berkeley · 분포 외 행동(out-of-distribution)을 회피하는 보수적 Q-learning. 양산 라인 적용의 유일한 안전 경로.
2021 · Decision Transformer
RL을 sequence modeling으로
UC Berkeley · (state, action, reward) 시퀀스를 GPT처럼 예측. 학습이 supervised이라 안정적.
2023 · DreamerV3
World Model 기반 RL — 단일 hyperparameter
DeepMind · 학습된 world model에서 상상 rollout. 150+ 태스크에서 hyperparameter 변경 없이 SOTA.
팹 적용 변형 — Applied Modification
  • Constrained CQL: 보수적 Q-learning에 안전 제약 (recipe 범위)을 hard constraint로 추가 (LG Display Mura RL 2023)
  • Shadow Mode Deployment: 학습된 정책이 실제 행동하지 않고 추천만 출력 → 엔지니어 사인오프 후 단계 승격
  • Multi-Agent OHT Routing: TSMC Hsinchu Fab 18에서 OHT(Overhead Hoist Transport) 동선 최적화에 multi-agent DRL 적용 (SEMICON Taiwan 2024)
  • Digital Twin + DreamerV3 패턴: 사내 fab digital twin을 world model로 학습 → 가상 환경에서 정책 학습 (개념 단계, NVIDIA Omniverse + Samsung 2024)

Diffusion 패밀리 — 결함 합성·EUV 추계 모델링

DDPM → Stable Diffusion → ControlNet → SDXL → FLUX
원본 — Origin
DDPM (Denoising Diffusion Probabilistic Models) · Ho, Jain, Abbeel · UC Berkeley · 2020
핵심 아이디어: 깨끗한 이미지에 노이즈를 점차 추가하는 forward process를 정의 → 그 역과정을 신경망이 학습. L = ‖ε − ε_θ(x_t, t)‖². GAN의 학습 불안정 문제를 우회.
Ho et al., "Denoising Diffusion Probabilistic Models", NeurIPS 2020.
주요 진화 (Evolution)
2021 · DDIM
Deterministic sampling — 50 step → 10 step
Stanford · 비-마르코프 sampling으로 추론 가속.
2022 · Latent Diffusion (Stable Diffusion)
VAE latent 공간에서 diffusion
CompVis · 픽셀 공간 대신 압축된 latent에서 학습. 계산량 1/10.
2023 · ControlNet
조건부 제어 — pose/edge/segmap

TW사례 4 · TSMC HGT 기반 수율 RCATier B

Hsinchu Fab 12/15/18 · Tainan Fab 18 · IEDM 2022 / 2023 발표

문제

5nm/3nm 공정에서 lot은 1500+ step을 거치며 수십 개 chamber를 통과. 한 lot의 yield 저하 원인이 어느 chamber의 어느 recipe step인지 사람이 추적 불가능. 전통 SHAP-on-XGBoost는 "feature 간 상관"은 잡지만 "lot이 어느 chamber 그래프를 통과했나"의 구조는 못 잡음.

베이스라인 (원본)
XGBoost + SHAP · feature engineering 기반. chamber-tool 정보를 one-hot 변수로 처리.
→
적용 (변형)
HGT (Heterogeneous Graph Transformer) · 노드 타입별 attention parameter 분리 · Time-aware edge timestamp · Yield label as node attribute

구체적 수정사항

  • Heterogeneous Node Types: chamber, tool, recipe step, lot을 각각 다른 노드 타입으로 분리. 타입별 attention head를 별도 학습.
  • Time-Aware Edge: 각 edge에 lot 통과 시간 정보를 positional encoding으로 추가. "2024년 5월 chamber A를 거친 lot"과 "2024년 6월의 같은 chamber"가 다른 분포일 수 있음을 학습.
  • Yield Label as Target: lot 노드에 final yield을 supervised target으로 두고 message passing 후 회귀.
  • SHAP on Graph: 학습 후 어느 chamber/edge가 yield 저하에 가장 기여했는지 GNN attention weight로 시각화.
