## 1. 재검증된 하드 팩트

`grep` 실측 기준(2026-08-18):

| 항목 | 실측값 |
|---|---|
| 게임 17종 중 광고 컨테이너(`data-lp-ad`) 보유 | **0 / 17** |
| 게임 17종 중 `lp-ad-policy=off` | **17 / 17** |
| 홈페이지 광고 정책 | **off** (`public/index.html:4`) |
| 블로그 광고 컨테이너 보유 파일 | 824 (단, 2026-08-13 홈·푸터 링크 제거됨) |
| `lpMountAds()` 호출하는 게임 | 7 (전부 무음 no-op) |
| sitemap 총 URL / 블로그 / 게임 | 433 / **372 (86%)** / **16 (3.7%)** |
| 블로그 디렉토리 총량 / noindex / 색인대상 | 1,943 / 1,573 / **370** |

### 핵심 함의

1. **수익 배선이 0%다.** `adSlots.js`는 `lp-ad-policy=off`인 페이지에서 조기 return 하고, `siteFooter.js`는 `[data-lp-ad]`가 없으면 아예 주입하지 않는다. 게임 17개는 두 조건 모두 해당 → **런타임에 `window.lpMountAds`가 undefined**. 7개 게임이 몇 달째 무음 호출 중.
   - ⚠️ `monetization_plan.md`의 "승인만 나면 코드 수정 0줄"은 **사실이 아니다.** 승인 후에도 2~3주 작업이 남는다.
2. **2026-08-13 게임 전용 전환이 광고 재고 100%를 껐다.** 재고가 있던 유일한 곳이 블로그(824개)였는데 사이트 구조에서 분리됨. UX 목적으로는 옳았으나 수익 관점에서는 순손실.
3. **구글이 보는 사이트는 아직 블로그다.** sitemap의 86%가 블로그이고 게임은 3.7%. 게다가 승인 엔진이던 수동 롱폼 80편이 **전부 고아 페이지(orphan)** 가 됐다.

### 반박되어 폐기된 항목 (백로그에서 삭제할 것)

- ❌ **"게임 페이지 화면밖 숨김 SEO 텍스트 = 구글 스팸정책 위반"** — 코드에 **0건**. `seo-hidden|sr-only|left:-9999|clip:rect|text-indent:-9999` 전수 grep 결과 없음. 이미 제거 완료된 사안이 메모리에 잔존해 브리프로 흘러들어갔고, 5개 분석 중 3개가 "최우선 리스크"로 증폭시킨 것을 적대적 검증이 잡아냄. **여기 8~15시간 쓰면 전액 손실.**
- ❌ **"광고 코드 준비도 100%"** — 실제 0%.
- ❌ **"wheelofnames 독점으로 카테고리 종료"** — 2위 spinthewheel.io가 2023-02 도메인 생성 후 3년 만에 월 2.0M·DR 69 도달. 헤드 키워드는 게임 오버가 맞지만 카테고리 전체가 잠긴 건 아님.
- ❌ **"sitemap에 고아 thin 372 URL이 등록돼 있다"** (실행 단계에서 반박) — sitemap 블로그 URL 372개 중 **noindex 0개**. 371개 전부 정상 색인 대상(중앙값 1,024단어). 실행했다면 양질 URL을 색인에서 제거할 뻔함.
- ❌ **"롱폼 큐레이션 인덱스를 새로 만들어야 한다"** (실행 단계에서 반박) — `/blog/`가 이미 `AUTO_RE`로 thin 자동글을 걸러 언어별 90~94편만 노출 중. 빠진 건 **인덱스가 아니라 그리로 가는 링크**였음(5분 수정).

> **교훈**: 멀티에이전트 분석은 방향을 잘 잡았으나, **개별 하위작업은 실행 직전 코드로 재확인해야 한다.** 이 감사에서만 브리프 오류 1건(hidden text) + 액션 오류 2건(sitemap, 인덱스)이 나왔고, 셋 다 실행했다면 순손실이었다.

## 5. 하지 말아야 할 것

### 함정 1 — 멀티플레이 부활 / 서버 랭킹 확대
인라인 `display:none` 제거는 30분이 맞다(bingo:447 / car-racing:588 / ladder:396,426 / lotto:630 / roulette:242,256 / team:322). 하지만 그 순간 열리는 건 **Supabase Realtime × 게스트 기기 N대 × 방코드/PIN × 카카오톡 인앱 WebView** 조합의 QA 지옥이다. `MEMORY.md`에 정확히 그 조합으로 하루를 날린 기록(모바일 WebView RLS 무음 실패)이 있다.
- 현실 공수 **20~40시간 + 영구 유지보수 부채**
- 서버 랭킹 12개: 스키마·RLS·점수 위조 대응 포함 **50~70시간** + 스팸 닉네임 관리라는 영구 운영 부담
- **버튼이 숨겨진 건 사고가 아니라 "미완성이라 껐다"로 읽는 게 합리적.** 부활이 아니라 제거가 순이득(액션 ⑤)

### 함정 2 — 영어 랜딩 30~50개 수작업 양산
제대로 된 랜딩 1개 = 6~10시간 → 30~50개면 **200~400시간 = 10~18개월간 다른 일 불가**. 랭킹 확인까지 3~6개월 지연이라 초기 10페이지 쓰는 동안 피드백 0. 게다가 **얇은 템플릿 페이지 양산 자체가 AdSense 승인을 더 어렵게 만든다**(자기모순). 1개 → 관측 → 분기만 허용.

### 함정 3 — 존재하지 않는 문제 + 저효과 채널
- hidden text 전수 감사 (코드에 0건, **8~15시간 전액 손실**)
- Adsterra·PropellerAds 팝언더 (월 $2~15 벌자고 운영자 원칙 훼손 + 재심사 인상 악화)
- 틱톡/스트리머/교사 커뮤니티 (각 3~6개월 누적 필요, 인디스쿨은 교사 인증 폐쇄형이라 진입 불가)
- **카카오 SDK 등록** — 5~7시간짜리 위생 항목이지 성장 레버가 아님 (K 0.0013→0.005 = DAU +1~3%, 측정 불가). 배관 끝에 카카오톡 네이티브 사다리타기가 앉아 있음. 액션 ①~⑤ 끝나고 시간 남으면 그때

## 6. 12개월 후 정직한 기대치

확률은 **운영자 행동 확률을 반영한 추정**이다. 근거: 16개월·1,671커밋 투입 후 마케팅 실행 0건, 최근 4개월 게임 실질 커밋 1건.

| 시나리오 | 확률(추정) | 내용 | 월수익 |
|---|---|---|---|
| **비관** | ~55% | 액션 목록 받고 첫 달에 지침, 또는 미착수. DAU 90~130 유지 | **$0** |
| **현실** | ~35% | ①~⑤ 완주(20~30h). DAU 130~250. 승인 반반 | 승인 시 $5~15 / 미승인 $0 |
| **낙관** | ~10% | 영어 랜딩 GSC 3,000+ 반응 → 자동화 확장, 승인 성공 | **$20~60** |

**월 $100은 세 시나리오 어디에도 없다.** 월 $1,000은 이 제품 형태·이 시간 예산에서 도달 목표가 아니라 **폐기 대상**이다. 정직한 최선 시나리오는 **"잘 되면 도메인 값을 번다"** 이다.

> 이건 실력 문제가 아니다. 16개월·1,671커밋으로 만든 것의 양과 질을 보면 실력은 명백히 충분하다. 문제는 **"한국어 × 게임 × 디스플레이 광고" 조합이 시장 구조상 막혀 있고**, 그 위에 **완성된 부품이 조립되지 않은 상태**가 얹혀 있다는 것이다. 앞은 못 고치고, 뒤는 20~30시간이면 고친다.

## 7. 검증자 간 미합의 쟁점

| 쟁점 | 대립 | 본 감사의 채택 |
|---|---|---|
| **A. 멀티플레이** | "8줄 해제" vs "40시간 부채" | **후자.** 근거: WebView RLS 사고 기록 + 4개월 커밋 1건. 단 DAU 300 넘기면 재검토 |
| **B. 영어 랜딩** | "미시도 레버" vs "이미 반증된 실험" | **"제대로 시도한 적 없음".** 3개 다 500단어 템플릿 복제. 그래서 1개 제대로 + 90일 킬 기준 형태로만 채택 |
| **C. N-to-1 관전 링크** | "DAU 3~5배" vs "마찰 5인분 추가" | **후자.** 카톡 내장 사다리타기가 이긴 이유가 정확히 기기 마찰 0. 게스트 세션은 광고 재고 0 페이지의 PV 1 |
| **D. AdSense 승인 확률** | 10~20% vs "조립하면 됨" | 게임당 300~800단어 집필(17개×2언어 = **60~120h**)을 넣느냐에서 갈림. **예산 초과라 미채택**, 대신 롱폼 복구(5~7h)로 대체하고 승인 확률을 낮게(25~40%) 잡음 |
