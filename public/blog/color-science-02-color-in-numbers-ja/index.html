色の科学 · 第2部

色を数にする

CIE 1931からCIEDE2000まで — 人類が色を測り座標に結びつけた一世紀
← 第1部  私たちはどう色を見るか

第1部で私たちは、色が結局L・M・S三つの数の比であることを見た。だが「私の見る赤」を他人に正確に伝えるには、感覚ではなく誰もが同じ値を得る標準座標が要る。1931年、国際照明委員会(CIE)は人を実験台に座らせて色を測り、その結果は今日のあらゆるディスプレイ・カメラ・印刷の土台になった。

1. 色を測る実験 — 等色

方法は意外に単純で美しい。円い視野を半分に分け、片側に測りたい単色光(一つの波長)を当てる。もう片側には三つの原色、赤(700nm)・緑(546.1nm)・青(435.8nm)を混ぜて当てる。

観察者は三原色の明るさのつまみを回し、両半分が同じに見えるよう合わせる。一致した瞬間の三値R・G・Bが、その波長の色を「三原色で表した座標」だ。すべての可視波長で繰り返すと、波長ごとに必要なR・G・Bの量を表す三本の曲線が得られる。

2. 等色関数 r̄ ḡ b̄

この三本の曲線が等色関数だ。r̄(λ)・ḡ(λ)・b̄(λ)は各波長の単色光を再現するのにR・G・Bがどれだけ要るかを示す。任意の光の色はこれで積分して得る。

ところが曲線を初めて見ると妙な点に気づく。r̄(λ)の一部が0を下回り、負になる。光を「負の量」加えるとは一体どういうことか。等色を学ぶ誰もがここで立ち止まる。

3. なぜ負になるのか

核心はこうだ。あるシアン(約500nm)の単色光は純粋で濃すぎて、赤・緑・青をいくら足してもそこまで濃いシアンにならない。混ぜるほど濁るだけだ。

そこで実験者は発想を逆転する。原色側ではなく、測りたいシアンの側に赤を少し足して濁らせ、残る緑+青と一致させる。式にすると「測る色 + 赤 = 緑 + 青」、つまり「測る色 = 緑 + 青 − 赤」。この引いた赤こそ負のr̄だ。

つまり負は「逆側に足した光」の記録だ。物理的に光を引くのではなく、引かねば一致しない色があるという人間の色覚の限界が数に刻まれたのだ。実在する三原色だけでは、あらゆる色を「正の量」で表せないことも意味する。

4. 負を消したX・Y・Z

負は計算に不便だった。そこでCIEは巧みな変換をした。実在しない三つの仮想原色X・Y・Zを定義したのだ。これらはどんな実在の光より濃い、物理的に作れない色だが、座標としては完璧に働く。

この原色で書き直すと、等色関数x̄・ȳ・z̄はすべて全域で正になる。さらにȳ(λ)は人の感じる明るさに一致するよう設計され、Y値一つが光度になる。

任意の光S(λ)に対し、下のように積分して三つの数X・Y・Z、すなわち三刺激値を得る。第1部の「L・M・S三つの数」がここでX・Y・Z三つの数に標準化されたわけだ。

X = ∫ S(λ) x̄(λ) dλ    Y = ∫ S(λ) ȳ(λ) dλ    Z = ∫ S(λ) z̄(λ) dλ

5. CIE 1931色度図 — 馬蹄形

三刺激値X・Y・Zは三次元で紙に描きにくい。そこで明るさを外し、「色相・彩度」だけを2次元に投影する(下の式)。その(x, y)平面が有名な馬蹄形の色度図だ。

外側の曲線は純粋な単色光のスペクトル軌跡、下の直線は赤と青を結ぶ純紫軌跡、中心は白色点。実在する全ての色がこの馬蹄形の内に収まる。ディスプレイの色の範囲(色域, gamut)はその中の三角形で描かれる — sRGB、DCI-P3、BT.2020と次第に大きな三角形になる。

x = X / (X+Y+Z)     y = Y / (X+Y+Z)

6. 1931の限界 — 均一ではない

CIE 1931は革命だったが一つ弱点がある。色度図上で同じ距離が同じ「色差」を意味しないのだ。

1942年マクアダムは人が「ようやく差に気づく」境界を測り、それは小さな楕円として現れた。問題はこの楕円の大きさと向きが位置ごとにばらばらなこと — 緑の領域では巨大(鈍感)、青では小さい(敏感)。座標上で二色の距離を測っても、人の感じる差に比例しない。

色を「管理」するには — 例えば二枚のパネルが十分近いかを一つの数で判定するには — 距離=差が成り立つより均一な座標が要った。

7. より均一に — CIE 1976 u'v'とCIELAB

最初の補正は、座標を非線形に引き伸ばしマクアダム楕円を可能な限り円に近づけることだった。こうして生まれたのがCIE 1976 UCS、u'v'色度図(下の式)。楕円がずっと均等に広がる。

同年CIEはさらに進み、明るさまで含む三次元均一色空間CIELAB(L*a*b*)を定義した。L*は明るさ(0黒~100白)、a*は緑(−)↔赤(+)、b*は青(−)↔黄(+)の軸で、第1部の反対色構造をそのまま座標にしたものだ。

変換はXYZを基準白で割り、立方根状の関数を通す。効果は単純だ。二色の差をただ二点間の距離として測れるようになった。

u′ = 4X / (X+15Y+3Z)     v′ = 9Y / (X+15Y+3Z)
L* = 116·f(Y/Yn) − 16
a* = 500·[f(X/Xn) − f(Y/Yn)]    b* = 200·[f(Y/Yn) − f(Z/Zn)]

8. 色差の完成 — ΔE76からCIEDE2000

CIELABで二色の差はユークリッド距離、ΔE*ab(下の式、1976)だ。直感的で長く使われたが、CIELABも完全に均一ではなく、特に青・高彩度領域で人の感覚とずれた。

そこで1994年、続いて2000年に補正式が出た。現在の産業標準CIEDE2000(ΔE00)は、明度・彩度・色相の差にそれぞれ重み(SL・SC・SH)を与え、彩度が高いほど差を弱く見積もり、青領域の色相-彩度相互作用を捉える回転項(RT)まで加える。

式は長く複雑だが、目的は一つ — 計算したΔE一つの数が人の実際の色差感覚に最大限合うようにすること。ΔE00が約1なら訓練された目がかろうじて区別する差で、それが今日のディスプレイ・印刷・塗料の品質基準になる。

ΔE*ab = √( ΔL*² + Δa*² + Δb*² )
ΔE00 = √[ (ΔL′/kLSL)² + (ΔC′/kCSC)² + (ΔH′/kHSH)² + RT·(ΔC′/kCSC)(ΔH′/kHSH) ]

二編を終えて

第1部が「眼が色をつくる」生物学なら、第2部は「その色を皆が共有する数に結んだ」標準の歴史だった。L・M・S三つの錐体に始まりX・Y・Z三刺激値、馬蹄形色度図、そしてCIEDE2000まで — 私たちが毎日見る画面の色を「正確だ」と言えるのは、この一世紀の測定のおかげだ。実際のディスプレイでこの座標が色域・キャリブレーション・カラーマネジメントにどう使われるかは、また次の機会に。
