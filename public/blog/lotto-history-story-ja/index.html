そういえばロトっていつからあるの？2000年の歴史の話を語ろう

2026-04-20 · 7分で読める · 🏛️ ロトの話

「ロト当たったら何する？」 — この会話、友だち同士で一度はやったことあるよね。でも考えたことある？ この「数字を選んで当たったら大当たり」っていう発想そのもの、いったいいつからあったんだろう？ 答えがちょっと衝撃的なんだけど、2000年を超えてる。ローマ皇帝も宝くじを引いて遊んでたし、ハーバード大学は宝くじのお金で建てられたし、朝鮮時代のうちのご先祖さまも同じことをしてた。今日はこの話を語ってあげるね。

🏯始まりは万里の長城の工事現場？（紀元前200年ごろ）

いちばん古い記録は中国の漢の時代。「万里の長城の工事費が足りなくて、民に宝くじを売った」っていう話があるんだよね。この部分はちょっと伝説化されているところがあって、学者によって意見が分かれるんだけど、80個の数字のうちいくつか当てれば賞金がもらえるゲームが漢の時代に実際にあったのは確かなんだ。名前が「白鸽票（はくごうひょう）」。鳩が当たり番号を運んできてくれたんだって 🕊️（もちろん訓練された鳩）。

面白いのは、中国の人たちがこれを大好きすぎて紀元前から今まで一度も途切れたことがない。西洋のカジノでやってる「Keno」っていう数字ゲームも、これをそっくりそのまま輸入したものなんだ。19世紀のアメリカ西部開拓時代に中国系移民が持ち込んで、カジノに定着させた。

TL;DR
ロトのDNA = 2200年前の中国・漢の時代。数字を当てる構造は最初から今までずっと同じ。

🏛️ローマ皇帝がパーティーで宝くじをばらまいた（紀元前1世紀）

これマジで笑える。ローマのアウグストゥス皇帝が宴会のときに客に番号の書かれた木片を配ったんだ。それを引いて景品をあげるっていうものだったんだけど、景品リストが今の基準でもえげつない: 奴隷、土地、家、船 😳。貴族たちが「今日は何が当たるかな」とドキドキしながら皇帝のパーティーに行ったっていう話が残ってる。

ネロ皇帝は一枚上手だった。市民の歓心を買おうと、円形闘技場で「タダの宝くじ」を大規模にばらまいた。当たれば土地と家を実際にくれたんだ。今でいうとインスタの「先着で1億ウォンイベント」みたいなもの。皇帝がSNSを運営してたようなものだね。

でもこれは「皇帝の遊び」レベルだから政治的な目的のほうが大きかった。定期的にチケットを買って引く今のロトとはちょっと違ってたんだ。

🎨本当の「現代ロト」の始まり — ルネサンスのイタリア（1500年代）

僕らが知ってる「数字を引いて現金をもらう」形のロトは、実は1500年代のイタリアで生まれたんだ。始まりがちょっと予想外なんだけど — ジェノヴァで市議会の委員5人を90人の候補の中から抽選で選んでたんだよね。でも市民がこれを見ながら「誰が選ばれるか」を私的に賭け始めたんだ。これが大ヒットすると、いっそ「人の名前」の代わりに「数字1〜90」に変えて、1530年にフィレンツェで世界初の国家公認の現金宝くじが登場する。名前が「La Lotto de Firenze」。今の僕らが使ってる「ロト（lotto）」って単語はここから生まれたんだ。イタリア語で「抽選、運命」っていう意味。

つまり今きみがロトって呼んでるもの、500年前のフィレンツェの人たちが使ってたその単語をそのまま使ってるんだ。イタリアのピザみたいに輸出された文化。🇮🇹

👑エリザベス女王も宝くじの運営者だった（1566年）

イングランドのエリザベス1世が1566年に国家宝くじを発行する。理由はあまりに単純 — 港の工事費が足りない。チケット1枚が10シリング（今の価値で約20万ウォン）、賞金は現金 + タペストリー + 銀食器セットだった。

でも面白いのは4年間、抽選をせずに売り続けただけ。1569年についに抽選したら40万枚くらい売れてたっていう記録。イングランド海軍の埠頭がこのお金で建てられたんだ。女王がクラウドファンディングをしたようなものだね。

🎓ハーバードが宝くじで建てられたって知ってた？

これマジ。アメリカ初期の大学はほとんどみんな宝くじ収益で建物を建てた。ハーバード・イェール・プリンストン・コロンビア — 1700年代の植民地時代に、教会や州政府が宝くじを売ってキャンパス建設費をまかなったんだ。「今日は誰が当たるかな」って人が集まってくると、その収益でアイビーリーグが建てられたってこと。🎓

しかもアメリカ独立戦争の資金も宝くじで調達しようとして失敗した歴史がある。1776年にContinental Congressが発行した「Continental Lottery」 — 戦争の軍費調達用だったんだけど、チケットがあまりに売れなくて結局イギリス・フランスからお金を借りることで終わった。ジョージ・ワシントンがこの宝くじチケットに直接サインしたんだけど、今コレクターの間で1枚あたり数億ウォンで取引されてる。

🧐 FUN FACT
アメリカ初代大統領ジョージ・ワシントンが署名した宝くじチケット1枚 = 現代の競売価格で$15,000〜50,000ほど。ジェファーソン・フランクリンも宝くじチケットを売っていた時代の話。

🎋朝鮮時代の韓国版ロト — 山筒契（サントンゲ／山筒契）

うちの国も負けてない。朝鮮後期（19世紀）に山筒契（サントンゲ）っていう契（頼母子講）の集まりがあったんだ。名前が面白い理由は竹の山筒（筒）に名前を書いた紙を入れて引いたから。10人〜100人くらいの人が毎月お金を集めて、一人を引いて目当てのまとまったお金を渡す方式。

今見るとただの「回ってくる契」なんだけど、引く瞬間の緊張感と当選のしびれるような快感はロトと同じだった。両班も常民もみんな参加して、当たればそのお金で畑を買ったり嫁入り道具をそろえたっていう記録が残ってる。朝鮮末期には全国的に流行して、一種の「庶民の銀行」の役割まで果たした。

でもあまりに流行したせいで詐欺をする人もすごく多かった。あらかじめ仕込んでおいて特定の人だけが当たるようにするとか。だから大韓帝国末期には政府が禁止したりもした。どの時代でも宝くじのあるところに詐欺もある 😅。

🎰現代ロトの誕生 — 1964年ニューハンプシャー

ここで面白い逆転。アメリカは19世紀後半から20世紀半ばまで宝くじがほとんどみんな違法だった。詐欺事件があまりに多かったから（朝鮮と似てる）。でも1964年にニューハンプシャー州が「教育費調達のための合法宝くじ」を初めて再開。これが成功して州ごとに真似し始めて、今はアメリカ45州が独自に宝くじを運営中。

Powerballは1992年に登場。複数の州が連合してジャックポットを数兆ウォンまで膨らませるモデルがこのとき初めて出てきた。「ジャックポット20億ドル」みたいなニュースのヘッドラインを見るの、たった30年しか経ってないシステムなんだ。

✨ 2000年で変わったものと変わらなかったもの

変わったもの:

  • 引く道具 — 木片 → 竹の筒 → プラスチックのボール → オンラインのRNG
  • 賞金のスケール — 土地1坪 → 2兆ウォンのジャックポット
  • 法的地位 — 皇帝の遊び → 国家による違法 → 合法宝くじ → 民間オンライン

変わらなかったもの:

  • 「自分が当たるかも」というドキドキ
  • 当たったら何をするか想像する時間の楽しさ
  • チケット1枚で変わるかもしれない運命に対する、人間の終わりなきロマン
