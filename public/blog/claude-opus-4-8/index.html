Claude Opus 4.8

무엇이 좋아졌나,
벤치마크로 본 자리

2026년 5월 28일, Anthropic 이 차세대 플래그십 Opus 4.8 을 공개했다. 정직성, 에이전트 코딩, 그리고 백만 토큰 장문에서의 도약. 공식 발표와 클라우드 모델 카드를 1차 출처로, 이전 버전과 경쟁 모델을 같은 표 위에 올려 본다.

Published 2026·05·29 · 9 min read · by Lucky Blog Editorial
Overview

한 줄로, 그리고 숫자로

Anthropic 이 2026년 5월 28일 차세대 플래그십 Claude Opus 4.8 을 공개했다. 직전 버전 Opus 4.7 발표로부터 약 41일 만으로, 최근 들어 부쩍 짧아진 출시 주기를 그대로 잇는다. API 모델 문자열은 claude-opus-4-8, AWS Bedrock 에서는 anthropic.claude-opus-4-8 로 부른다.

이 글은 공식 발표 자료와 클라우드 모델 카드(1차 출처) 를 기준으로 무엇이 좋아졌는지, 그리고 이전 버전·경쟁 모델과 벤치마크가 어떻게 비교되는지를 팩트 위주로 정리한다. 수치 중 일부는 Anthropic 공식 벤치마크 표가 이미지 형태로 제공되어 본문 텍스트로 직접 노출되지 않는다. 그 경우 표를 전사한 신뢰도 있는 2차 매체 수치를 교차검증해 실었고, 표 아래 주석에 그렇게 표시했다.

What's New

4.7 대비, 무엇이 좋아졌나

① "정직성"이 이번 업데이트의 간판이다. Anthropic 은 Opus 4.8 을 "진행 상황에 대해 더 정직하고, 더 오래 독립적으로 일할 수 있는" 모델로 소개했다. 가장 구체적인 수치는 코딩 영역에서 나온다. 자기가 작성한 코드의 결함을 지적 없이 그냥 통과시킬 확률이 이전 세대 대비 약 4배 줄었다. 근거 없는 단정을 줄이고 불확실성을 표시하는 경향도 강해졌다.

② 정렬(alignment)·안전성 지표가 개선됐다. Anthropic Alignment 팀은 기만·오용 협조 같은 "misaligned behavior" 비율이 4.7 대비 눈에 띄게 낮아졌다고 밝혔다. 보도된 정량 지표로는, 모델당 수천 회 시뮬레이션에서 misalignment 점수가 약 2.5(4.7)에서 약 1.9(4.8) 로 내려갔다(2차 매체 인용).

③ 에이전트 코딩과 장문 컨텍스트가 크게 향상됐다. 뒤의 표에서 보듯 SWE-bench Pro 와 1M 토큰 장문 추적(GraphWalks)에서 폭이 가장 컸다. 기본 effort 가 high 로 상향돼, 4.7 과 비슷한 토큰을 쓰면서도 더 나은 결과를 낸다.

④ 속도와 비용. 새 Fast mode 는 표준 모드보다 약 2.5배 빠르고, 이전 세대 fast mode 대비 약 3배 저렴하다. 표준 가격은 4.7 과 같다($5 입력 / $25 출력, 100만 토큰당).

Features & Context

새 기능과, 가속하는 주기

  • Dynamic Workflows (research preview) — 수백 개의 subagent 를 병렬로 조율해, "수십만 줄 규모 코드베이스 마이그레이션을 kickoff 부터 merge 까지" 자동 수행하는 것을 목표로 한다. Claude Code 에서 프리뷰.
  • Effort control 슬라이더 — claude.ai 와 Cowork 에서 사고 깊이를 직접 조절. 높이면 더 깊게 추론, 낮추면 빠르고 rate limit 을 아낀다.
  • Messages API 작업 중 system message — 프롬프트 캐시를 깨지 않고 작업 도중 지시를 갱신.
  • 가용성 — Claude 앱(Pro·Max·Team·Enterprise), Anthropic API, Claude Code, 그리고 AWS Bedrock·Google Cloud Vertex·Microsoft Foundry 전부.
  • 캐싱·배치 — 프롬프트 캐싱 최대 90% 절감, 배치 처리 50% 절감(4.7과 동일 정책).

Opus 시리즈는 4.5(2025.11) → 4.6(2026.02) → 4.7(2026.04) → 4.8(2026.05)로, 갈수록 간격이 좁아지고 있다. 같은 주에 Anthropic 이 대규모 자금 조달과 상위 모델 "Claude Mythos" 의 임박을 알렸다는 보도도 나왔다. 다만 이 부분(조달 규모·Mythos 일정)은 언론 보도·예고 단계이며 Anthropic 의 1차 확정 문서로는 검증되지 않았으므로, 본문에서는 단정하지 않는다.

팩트 기준 안내

출시·가격·컨텍스트·컷오프·가용성은 Anthropic 공식 발표와 AWS Bedrock 모델 카드(1차 출처) 로 확인했다. 개별 벤치마크 수치는 공식 표가 이미지로 제공되어, 이를 전사한 신뢰 매체(VentureBeat, llm-stats, digitalapplied, Artificial Analysis) 값을 교차검증해 실었다.

MMLU·AIME·ARC-AGI 등 공식 수치가 확인되지 않은 항목은 의도적으로 제외했다. 경쟁사 수치는 측정 조건이 달라 참고용이다.
