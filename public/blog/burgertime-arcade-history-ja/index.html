BurgerTime — 非暴力フード系ゲームが Cooking Mama・Overcooked へ進化した道のり

2026-05-10 · 8分で読める · 🍔 Game History

1982年、日本のあるゲーム会社が奇妙なゲームを作った。シェフが巨大なハンバーガーの具材の上を駆け回り、一段ずつ落としてハンバーガーを組み立てる。敵は宇宙人ではなくホットドッグ・ピクルス・たまごだ。暴力なし、死もなし、ただ料理するだけ。その年のアーケードを支配していたのは Pac-Man・Donkey Kong だったが、この小さなゲームが40年後の Cooking Mama・Overcooked へと続くフード系ゲームというジャンルの始まりになった。データイーストと BurgerTime の、忘れられた舞台裏。

🍔1982年 — アーケードのルネサンス期

BurgerTime が登場した1982年はアーケードゲームの黄金期だ。1980年の Pac-Man、1981年の Donkey Kong に続いて、1982年には Ms. Pac-Man、Galaga、Pole Position といった名作が次々と生まれた。日本の会社のあいだには明確な序列があった。

  • 1位 Namco(ナムコ) — Pac-Man、Galaga などのアイコンを保有
  • 2位 Taito(タイトー) — Space Invaders の元祖、Bubble Bobble など
  • 3位 Sega(セガ) — シミュレーター・アーケードの強豪
  • 4位 Data East(データイースト) — 1976年創業、日本で4番目に大きなアーケード会社

データイーストは日本語の略称「DECO」として知られていた。ほかの3社のような超ヒット作はなかったが、「変わっているけれどマニア層に愛される」コンセプトのゲームを作るのが上手い会社として名を馳せていた。この会社の4番目の新作が BurgerTime だった。

👨‍🍳デザイナー、土地基忠 — 「食べ物で作ろう」

BurgerTime のデザイナーはMototada Tochi(土地基忠)だ。日本の原題は「ハンバーガー」だった。1982年の時点で、データイーストに入社してまだ間もない若手デザイナーだった。

彼が思いついたコンセプトはシンプルだったが、当時としては型破りだった ── 「プレイヤーがシェフになるゲーム」。敵を倒すのでも、宇宙を救うのでもなく、ただハンバーガーを組み立てるゲーム。岩谷の Pac-Man が非暴力の最初の試みだったとすれば、BurgerTime はそこからさらに一歩進んで、「労働・生産がメインの動詞」であるゲームだった。

デザインはこうなった。

  • 主人公 Peter Pepper — 大きな鼻のシェフキャラクター、白い帽子にエプロン
  • マップ＝はしごとプラットフォーム — 図式化された巨大なハンバーガー店
  • ハンバーガーの具材が分散配置 — 上のバンズ、肉、レタス、下のバンズ
  • 具材の上を歩くと一段下に落ちる — すべての段を落としきればハンバーガー完成
  • 敵キャラクター3種 — Mr. Hot Dog(赤)、Mr. Pickle(緑)、Mr. Egg(黄)
  • 防御武器＝コショウ — 敵を一時停止させる(倒さない)非暴力の武器
FUN FACT
「Peter Pepper」という名前は、コショウ(pepper)をふりかけるシェフという意味と、その時代のアメリカ漫画キャラクターの命名トレンド(同じ子音の頭韻)を同時に狙ったネーミングだ。日本名では単に「シェフ」だったが、アメリカでの発売時にキャラクターへ個性を与えるために加えられた。

🌭非暴力デザインの真髄

BurgerTime が本当に興味深いのは、「暴力のないゲーム」のデザインがどう機能するのかをよく見せてくれる点だ。敵を倒せないのだから、コショウはただの一時停止にすぎない。では、ゲームの緊張感をどうやって保つのか。

土地の答えは「敵を活用する」ことだった。Mr. Hot Dog のような敵がハンバーガーの具材の上にいるとき、プレイヤーがその具材を落とすと敵も一緒に落ちる。すると得点ボーナス。「敵を倒す」代わりに「敵をハンバーガーの具材に挟み込む」といったメカニクスだったわけだ。残酷とも見えるが、デザインの面では暴力を労働の副産物へと変換する巧妙なトリックだった。

この非暴力・労働中心のデザインは、その時代としては本当に珍しかった。Pac-Man が「食べる」なら、BurgerTime は「組み立てる」。ゲームの動詞の多様化に一歩貢献したわけだ。

📺アーケード → 家庭用 → マニア層への定着

1982年に日本・アメリカのアーケードで発売された後、BurgerTime はメガヒットではなかった。同じ年の Pac-Man・Donkey Kong の陰に隠れ、筐体の出荷台数に明確な公式記録はないものの、その2作の10分の1程度だったのではという推算がある。

ところが1983年の Mattel Intellivision 向け家庭用移植版が爆発的に売れた。Intellivision は Atari 2600 のライバル機だったが、BurgerTime はそのコンソールのキラーアプリの一つになった。Intellivision のベストセラーゲーム トップ5に入ったのだ。家庭用市場のほうが強かった、珍しい事例である。

その後1980年代を通じて、NES、Atari、ColecoVision、Apple II、Commodore 64 などほぼすべての家庭用コンピューター・コンソールに移植された。超ヒットではなかったが、マニア層が粘り強く形成されたゲームだった。「あの頃 BurgerTime が好きだった」という人は、今も少なくない。

🔄リメイク — 1991、2007、2009

BurgerTime は30年以上にわたって絶えずリメイクされてきた。そのたびに完全な成功というわけではなかったが、データイースト(のちには IP の所有者)が地道に再リリースを重ねたゲームだ。

リメイクはどれもマニア中心にしか売れなかった。だがこのゲームの本当の影響力は「フード系ゲームというジャンル」の始祖としての役割だった。直接の続編としてではなく、このゲームが投げかけたコンセプトを次の世代のデザイナーたちが受け継いだのだ。

🍳Cooking Mama (2006) — DS の料理革命

2006年に Nintendo DS で発売されたCooking Mamaは、BurgerTime の精神的な後継作と言える。日本の会社 Office Create が作ったこのゲームは、「プレイヤー＝料理人」というコンセプトをさらに一歩進化させた。

  • DS のタッチスクリーンで玉ねぎを切る、卵を割る、フライパンで転がすなど、実際の料理動作のミニゲーム
  • 実在する料理レシピ30種類以上(オムライス、カレー、ハンバーガー、ラーメンなど)
  • ママのキャラクターが励まし・評価してくれる
  • BurgerTime と同じく非暴力、ただしリアルな料理シミュレーション

Cooking Mama は全世界累計1,400万本以上を売り上げたメガヒットになった。BurgerTime が投げかけたコンセプトを「本物の料理シミュレーター」へと発展させたわけだ。日本の Nintendo DS 時代を代表するライフスタイル系ゲームとして定着した。

🔥Overcooked (2016) — カオスな協力料理

そしてもう一度の進化が、2016年のイギリスのインディースタジオGhost Town Games の Overcookedだ。このゲームは BurgerTime のもう一つの側面 ── 「料理＝時間のプレッシャー＝カオス」を極限まで高めた。

  • 2〜4人での協力マルチプレイ
  • 制限時間内にさまざまな注文をさばく
  • キッチンがどんどん崩れていく(船・トラック・動く橋など)
  • 役割分担ができないと、友達・恋人の関係が崩壊する

Overcooked は「カップル・友情を試す」ゲームとしてミーム化し、200万本以上を売り上げるインディーヒットになった。続編の Overcooked 2(2018)はさらに大きな成功を収めた。BurgerTime の「ハンバーガーの具材を落として組み立てる」メカニクスが、40年後にマルチプレイヤーのカオスな料理へと進化したわけだ。

📉2003年、データイーストの倒産

悲しいことに、BurgerTime を作ったデータイーストは2003年に倒産した。1990年代に入って会社はさまざまなジャンル(アクション、シューティング、格闘)に手を出したが超ヒットを出せず、格闘ゲームの強豪だった SNK・Capcom のあいだで市場を失った。27年の社史が幕を閉じた。

BurgerTime の IP は別の会社へ売却された。現在は日本の会社 G-Mode が IP を保有しており、先に挙げた BurgerTime Party!(2018)のような続編は G-Mode のライセンスで作られたものだ。生み出した会社は消えても、IP は生き続けているという、ゲームの珍しい事例である。

🎯今日における意味 — 「労働をゲームに」の始まり

BurgerTime を今あらためて遊んでみると、一つのことがはっきりする ── このゲームが「労働をゲーム化する」デザインの原型だということ。シェフになってハンバーガーを組み立てるというコンセプト、それがその後40年にわたってゲーム業界が「プレイヤー＝職業人」というコンセプトへと無数に変奏していく出発点だった。

Cooking Mama、Overcooked だけがそうなのではない。Stardew Valley(農夫)、Animal Crossing(島の管理者)、Powerwash Simulator(掃除人)、House Flipper(内装業者)、PowerWash Simulator ── どれも「プレイヤーが何らかの職業をシミュレーションする」ゲームだ。BurgerTime が1982年に投げかけた「ありふれた労働をゲームにできる」という可能性が、ジャンル一つをまるごと生み出したのだ。

非暴力・生産・日々の労働を楽しさへと変換するデザイン ── ゲームデザインの、最も平和でいて最も巧妙な系統だ。BurgerTime は、その系統の始祖だった。
