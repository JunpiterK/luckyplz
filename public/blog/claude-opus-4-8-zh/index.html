What's New

相比 4.7 有何提升

① "诚实性"是本次的招牌。 Anthropic 将 Opus 4.8 定位为"对自身进度更诚实、能更长时间自主工作"的模型。最具体的数字出现在编码领域：把自己代码中的缺陷不加提示就放过的概率，较上一代约降低为四分之一。 同时减少无依据的断言，更善于标示不确定性。

② 对齐（alignment）与安全指标改善。 Anthropic 对齐团队称，欺骗、协助滥用等"misaligned behavior"的比例较 4.7 显著下降。被报道的量化值为：每个模型数千次模拟中，misalignment 分数由 约2.5（4.7）降至约1.9（4.8）（二手媒体引用）。

③ 智能体编码与长上下文大幅提升。 如后表所示，SWE-bench Pro 与百万 token 长文追踪（GraphWalks）的涨幅最大。默认 effort 上调为 high，在与 4.7 相近的 token 预算下产出更好。

④ 速度与成本。 新的 Fast mode 比标准模式约快2.5倍，较上一代 fast mode 约便宜3倍。标准价格与 4.7 相同（输入 $5 / 输出 $25，每百万 token）。

Features & Context

新功能，与加速的节奏

  • Dynamic Workflows（research preview） — 并行编排数百个子智能体，目标是"将数十万行规模的代码库迁移从 kickoff 到 merge 全自动完成"。在 Claude Code 中预览。
  • Effort control 滑块 — 在 claude.ai 与 Cowork 中直接调节思考深度；调高则推理更深，调低则更快并节省 rate limit。
  • Messages API 任务中系统消息 — 在不破坏提示缓存的情况下，于任务中途更新指令。
  • 可用渠道 — Claude 应用（Pro·Max·Team·Enterprise）、Anthropic API、Claude Code，以及 AWS Bedrock·Google Cloud Vertex·Microsoft Foundry 全覆盖。
  • 缓存与批处理 — 提示缓存最高省90%，批处理省50%（与4.7同策略）。

Opus 系列经历 4.5（2025.11）→ 4.6（2026.02）→ 4.7（2026.04）→ 4.8（2026.05），间隔不断缩短。有报道称同周 Anthropic 完成大额融资并预告上位模型"Claude Mythos"将至。但这部分（融资规模、Mythos 时间）属 媒体报道/预告阶段，Anthropic 一手确定文件尚未证实，故本文不作断言。
